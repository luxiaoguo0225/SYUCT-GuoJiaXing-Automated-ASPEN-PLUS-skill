# 收敛设置、分离模型与节能结果的真实性（M02/M06/M08/M09）

适用：严格精馏、强非理想/多相体系、循环、双效/MVR及其整改交付。本文沉淀判断方法，不提供可直接套用的塔参数、容差或节能率。

本技能的验收边界：特殊情况下可以选择自定义收敛；容差不得放宽；不能用SEP或自定义模块凑分离结果。当前任务的明确指令优先。不要把某次任务对Custom的禁用扩大为通用禁令，也不要将用户的精度约束误写成Aspen软件的能力限制。

## 1. 自定义收敛、指定分离与自定义物理模型分开判断

| 对象 | 改变什么 | 结果可以证明什么 |
| --- | --- | --- |
| RadFrac内置预设或Custom | 同一塔模型的算法、初始化及迭代策略等求解设置；另须单独核验收敛判据 | 满足相应方程与判据的数值解；不能单凭收敛证明物性准确或设备可实现 |
| SEP / SEP2 | 按给定规格分配组分；SEP本身是内置模块 | 给定分配假设下的物流计算，不能预测一座严格塔达到该分离的能力与实际能耗 |
| 用户模型 / ACM等 | 单元内部的机理或经验关系 | 仅限已定义方程、参数数据和独立验证所支持的范围；并非冠以“自定义”就更真实 |

不要把Custom等同于直接指定回收率，也不要因软件提供某个选项就认为无需依据。SEP有已知分离数据的黑箱表示用途；在需要预测分离性能的任务中，不得把目标回收率直接写成SEP输入后，声称已验证严格分离。FSplit的同组成物流分支与SEP的选择性组分分配不同；依据实际用途判断，不能只靠名称黑名单。

严格塔的产品Design Spec也不等于伪造结果：目标必须由真实操纵自由度通过完整塔方程求解，且满足物理约束；不得覆盖计算输出。

## 2. 何时可以选择Custom，以及应留下什么证据

先检查物性与相数、压力路径、规格和自由度、参数缺失、初值相态。内置预设与体系匹配时优先采用，不因一次失败就无依据地切换；不要求为了证明必要性盲试所有预设。

若残差振荡、强耦合、初始化失效等诊断支持调整数值策略，可在用户允许的范围内使用Custom。记录：失效现象及诊断依据、原预设及实际算法、每项修改前后值、理由、最终实际容差，以及复算结果。增加迭代次数或改变阻尼并不自动放宽残差标准，但必须说明必要性；不能用它们掩盖不可行的规格。

读取并保存本机真实字段，例如已核验版本中的`CONV_METH`、`ALGORITHM`、`INIT_OPTION`、`MAXOL`、`DAMPING`、`TOLOL`；这些是定位线索，不是跨版本固定接口。内置预设也可能自动选用Newton等算法，不能仅凭算法名断言“使用了Custom”。同样，不能只改选择标签而隐藏仍生效的手动设置。保存后独立重开，运行前后都读回实际选择和参数。

## 3. 容差看实际判据，不能只看输入框

输入字段、预设默认值与报告中的实际方程容差可能存在缩放或转换。曾出现原始输入值与实际塔方程容差不同的情况；因此不能仅凭字段数值判断是否更严格，也不能把换预设后的默认值自动当作合格值。

- 先留存原模型的输入、导出报告及实际收敛判据，再修改。逐对象核验塔方程、闪蒸、循环、Design Spec和其他实际启用的容差。
- 对同一残差定义、缩放及比较方式，实际误差限只能保持或收紧。若定义/缩放改变，原始数字大小不能直接证明精度关系，应另行核实等效判据与物理残差；无法比较就明确未验证。
- 审计至少记录`对象 / 判据 / 原输入 / 新输入 / 原实际值 / 新实际值 / 残差定义与缩放 / 是否放宽 / 来源`。保存、重开及运行后再次核对，不能用事先的设值语句代替读回证据。
- 报告可能采用省略E的Fortran指数，例如`0.100000-08`表示`1e-9`；不要误读为普通小数或减法。未找到判据不能按零值或默认通过处理。
- 严格判据未达到、迭代超限、或相关循环未闭合时，如实报告失败；不得放宽判据、删日志或改验收脚本使其通过。

## 4. 独立重开可复现，不等于初值无关或工程验证完成

在独立临时目录、新COM文档/引擎中打开交付副本，复算并保留最新`.his`、完整性、块/循环/DS状态、实际设置、总量/组分/能量衡算及产品与排放指标。核对实际模块类型及执行记录，避免仅看流程图标签或报告生成段落。复现脚本不得暗中修改待验模型的求解设置、规格或结果。

从已收敛工况提取塔内温度/组成分布和撕裂流初值是可用的初始化方法，但必须披露。保留这些明示初值后的独立重开，只支持可复现性；不能称为“无初值启动”，也不证明任意初值收敛、唯一解或稳定物理解。强非理想/多液相或疑似多根时，按风险检查相稳定性、温度/组成分布及有依据的不同初值。

数值收敛、物性适用性、分离指标、水力学、设备评级和动态可操作性是不同证据层级。干净日志与小残差不能补足相平衡参数的外推数据、真实压头/NPSH或设备能力证据。

## 5. 串联双效靠物料连接证明，两类节能技术靠机理与贡献证明

串联/并联先由物料拓扑定义：串联要求上游塔某一实际出口作为下游塔进料，且物料去向可追溯；具体进料分配和出口选择由当前方案确定。共同原料分到两塔后只作热耦合，仍是物料并联，不能标成用户要求的串联。压力高低或先后顺序不作为通用定义。

双效利用不同压力形成的温位差，将一效可用热量供给另一效；MVR通过轴功压缩提升蒸气温位。用户要求两类技术时，应分别给出真实连接、可用热源、接收负荷、传热温差及各自热量贡献，不能重复命名同一热回收，也不能为“串联”图形而添加无物理依据的物流。

热耦合须核验供需负荷、压力降及整个换热路径的最小温差；多组分相变时只查端点温差不足。离散焓路径闪蒸可用于独立筛查，但有限采样不证明连续全程无夹紧，也不能代替面积与设备评级。MVR另核压缩机入口相态、出口温度、压比及该压力范围的汽相物性适用性。

## 6. 节能比较冻结边界，结果按证据命名

基准、双效、双效加MVR采用相同进料、产品/排放规格、溶剂与补料核算、公用工程及产品终态边界。若为修正物理问题增设冷却或其他设备，应检查各方案是否需要相同修正；不能沿用已失去可比性的旧基准。

分别列外供蒸汽/热量、压缩机与泵轴功、加热器、制冷和冷却负荷。内部回收热不能一边抵扣外供热、一边再次计入节能收益。蒸汽降低不自动等于总能耗或费用降低；总一次能源、碳排放或费用结论需要明确换算、制冷效率或公用工程价格来源。无相应依据时只报告可核验的热量、电功和蒸汽变化。
