# 教材原理：收敛、优化、经济评价与自定义模型（M08/M09/M14）

来源 S04 第9、11、12章；S06 Tutorial 3/6/9/10、Bonus 2；S07 第1、8–12章；S08 第1、3章。教材求解思想与 Aspen 具体 API 区分，来源定位见 [覆盖表](textbook-source-coverage.md)。原理后读 [案例对应](principle-case-map.md)。

## M08-K01 序贯模块、联立方程和联立模块

序贯模块按物流拓扑求单元，循环用撕裂与迭代闭合；联立方程一次联立流程未知量及方程；联立模块保留块求解与流程联立的部分结构。方法改变数值行为，不改变物理守恒和自由度。大型/强耦合系统的缩放和初值尤其重要。

Aspen 的 SM/EO 能力和支持单元需本机确认。不要在一个物理不可行的模型上无限更换求解器；先检相态、压力、规格相容和缺参数。来源：S08 §1.2–1.4（PDF16–40）；S04 §12.1。

## M08-K02 撕裂变量、缩放与收敛判据

循环写为 `x=g(x)`，残差 `g(x)-x`；直接迭代、Wegstein、Newton/Broyden 对耦合程度和非线性敏感。温度、压力、总量和痕量组分量级不同，应定义相容缩放和绝对/相对公差。只闭合总流量可能仍有组分或焓漂移。

尽量先用开环运行得到合理 T/P/组成/相态，再闭环。撕裂流初值不是固定外部进料，不能同时作完整 STREAM 规格。收敛需独立查组分/能量残差与块状态，并保存新开冷启动证据。来源：S04 第11、12章；S08 §1.2。

合理初值仍可能因迭代映射振荡而不收敛。用残差形态区分增加次数、阻尼/耦合求解、内层精度和物理不可行；分率启动规格须显式定义进料/组分基准，最后恢复用户产量目标。见[消化判断R28–R32](sun-lanyi-case-derived-reasoning.md#m08)。

## M08-K03 Design Spec 与 Vary 的可解性

目标和可调量必须有有效响应，一项独立目标对应一个独立操纵自由度；若两个目标由同一物理关系锁定，增加 DS 不会创造自由度。区间应物理有效且尽量包住根，目标响应接近零或多根时 SECANT 等方法可能失败。

先在范围内扫描响应/相态再启用 DS；冻结其他规定，避免 Calculator 与 DS 同时写同一输入。计算输出是只读结果，不能写入结果节点伪造达标。来源：S04 §9.1–9.4；S06 Tutorial 3；S08 §1.1。

## M08-K04 Calculator、执行顺序与再计算

Calculator 可把需求关系、补料或经验关联式转为输入更新，但必须区分 Import/Export 变量及执行顺序。依赖下游结果写回上游产生隐含循环；一次执行的数值不一定对应最终收敛结果。Transfer/Balance 也不能消除实际守恒方程。

核对写入对象、单位、运行时刻和重新执行结果；需要闭环时配合撕裂或设计规定。保留变量定义和有来源的公式，不能用 Calculator 强制覆盖矛盾物理结果。来源：S04 §9.3–9.5；[执行经验](calculator-flowsheeting-options.md)。

## M08-K05 Sensitivity 与优化不同

Sensitivity 描述候选响应；Optimization 需要明确目标函数、变量范围、约束及求解策略。变量有连续、离散、拓扑三类，板数/进料级等应按整数处理。局部最优、边界最优和全局最优不能混称。

保留全部候选的状态和失败原因，ROWSTAT/有效行筛选后才比较。不要把失败点用零负荷或极好目标值纳入排序；目标曲线不连续时检查相变/规格切换。来源：S04 §9.6–9.7；S08 第3章；S06 Tutorial 6。

## M08-K06 标定、拟合与数据调和

拟合是识别模型参数；数据调和利用守恒和测量精度调整测量，二者不能混成“让模拟等于实测”。先识别异常/系统误差及单位，再讨论加权残差和参数可辨识性。足够小的拟合残差不证明物理模型正确。

独立保留验证工况并检查预测外推。Aspen 流股 `Reconcile()` 用于初值/循环协调的功能必须与统计数据调和概念区分，不声称调用它完成测量不确定度分析。来源：S04 §9.8、第12章；S07 第9章。

## M08-K07 诊断与最终验收分开

历史运行的累计错误可能来自迭代初始干板/温度交叉，块最终正常并不自动清掉累计消息。诊断时联合读 `.his`、块/撕裂/DS状态和物理残差，判断根因；严格干净交付仍要求重新初始化、保存、独立新开后满足用户要求的 `.his` 与 Control Panel 0/0/0。

不能通过删日志或只看最终块状态取消验收。若仍有无法清除的警告，明确未达标及影响；源码/文档验证通过也不代表相应设备已做 Aspen 运行验证。来源：S04 第12章；[运行验证](run-verification-and-reconcile.md)及现有案例证据。

## M09-K01 自动化和自定义模型的层次

COM 外部控制修改输入和读取结果；Calculator 补充计算关系；用户模型/ACM 表示单元内部方程；物性用户接口是另一层。它们的输入输出和执行时刻不同。外部循环不能弥补不正确的内部机理，也不能写只读输出当计算结果。

在本机核对公开接口、字段单位与版本，把设备方程和控制脚本分开验证。许可、并发、数据依赖、初始化和异常返回会影响可复现性。来源：S06 Tutorial 9；S04 §9.3、第12章。

## M14-K01 自定义块需要守恒和极限检验

标准块不能表达膜、特殊结晶/传递或经验单元时，先定义所有端口、状态量、方程、未知参数与自由度，再选择 Calculator/用户模型/外部程序。需检查零流、零驱动力、无反应、无压降和极端回收等极限行为。

与 Aspen 接口以质量、元素、焓和压力保持闭合；参数用独立实验/权威来源验证。模型缺参数时可以报告可行范围，不能把模板计算包装成已验证设备。来源：S06 Tutorial 9；S08 §1.1、1.3。

## M14-K02 资本成本的估算口径

采购成本、安装成本、总固定投资和总项目投资有不同边界。设备规模指数/成本指数必须有来源及适用规模、材质、压力、地区、年份、货币；通用幂律外推不适用于极小/极大或不同结构设备。成本软件映射还要核设备身份和尺寸。

经济任务才进一步读取本节。输出各设备过程尺寸、成本基年、换算方法、安装因素和估算等级；流程块数量不等于实体设备数量，外置冷凝/再沸连接也可能只是已有设备显式化。来源：S07 第12章；S06 Tutorial 10，PDF207–227。

## M14-K03 操作费用、TAC 和盈利

运行费用包含原料、能源、补料/溶剂/催化剂、人工、维护和废物；年度运行小时要显式给出。`TAC=年化资本+年度运行费`，年化规则/寿命/贴现不同则结果不同。NPV/IRR/回收期还需现金流、产品价格、税与产能利用条件。

先冻结价格和共同边界，避免把蒸汽回收收益和原蒸汽消耗减少双计。经济最优需产品与设备可行约束；没有价格/年化依据时只报告热电或成本范围，不编造盈利性。来源：S07 §12.2–12.3；S05 §2.3；S06 Tutorial 10。

## M14-K04 优化约束和算法选择

写明 `min f(x)` 与等式、上下限、不等式及离散变量。无约束驻点不一定是极小值，约束最优可能落边界；梯度/SQP 对可微模型有优势，无梯度/启发式可处理噪声但不自动保证全局最优。缩放、初值和可行域比算法名称更重要。

先有已验证基准，再设计搜索和停止标准，最后把推荐解回完整 Aspen 模型重算。最优点不能来自失败/外推或违反水力、温度/压差的工况。来源：S08 第3章，PDF99–143；S06 Tutorial 6/Bonus 2。

## M14-K05 降阶/代理模型与外推

ROM 由完整模型或实验样本训练，需要覆盖可行域并分出训练/验证点。拟合精度高不等于未采样拓扑/相变区域正确，外推尤其危险。可行性分类和目标回归宜分开处理失败工况。

保存输入、结果、状态、版本、物性和案例哈希；用代理加速筛选后，推荐方案回完整模型验证，并对不确定性留余量。不得把机器学习预测的负流量或假高收率当模型结果。来源：S06 Bonus 2，PDF293–339。

## M14-K06 批量并行、许可和故障隔离

并行多个案例缩短扫描时间，不代表一个 COM 单次求解会同比加速。每个进程应有独立 COM 文档、目录和文件名，避免共享文件、日志或结果树；并发数由许可和内存/CPU实测决定。

工作进程处理运行超时/崩溃，关闭自己创建的对象，保留失败数据，不结束用户其他 Aspen 进程。先用少量独立点验证一致性，再扩大；最终点仍新目录冷启动。来源：S06 Bonus 2；本机机制另见 [COM与许可](com-attach-and-license-env.md)。
