# 精馏建模前的相图分析与应用

适用入口：M01-K04–K07、M02-K01/K08–K10。**在搭建精馏工段前，先核验物性，再计算适用相图并据此筛选方案。** 相图用于热力学判断，最终操作参数仍需严格塔和设备校核。修复已有工段时，先在工作副本补做这一步，再决定是否修改拓扑或规格。

## 1. 先核验生成相图所用的物性

- 核对实际生效的方法、气相处理、组分身份、必需二元参数及方向、来源/版本、方程、单位与温压范围。选择 NRTL 等方法名本身不证明参数已加载；缺参不能填零冒充数据。
- 检查实际进料、候选产品及热冷端覆盖的 VLE；可能分相时联查 LLE/VLLE 和相稳定性，不能强制单液相获得表面平滑的图。
- 区分实验验证、数据库范围内预测、参数外推和接口功能试验。缺参、范围不适用或相数未确认时，可做明确标注的探索分析，但不得据此批准物理可行或最终设计；列明需要补齐的证据。
- 具体数据审计见[物性来源与修复](property-provenance-and-repair-gates.md#m01)，原理见[物性与相平衡](textbook-properties-and-boundaries.md)。

## 2. 按体系和目标选择图型

| 体系/问题 | 搭塔前分析 | 用于判断 |
|---|---|---|
| 二元精馏 | 候选操作压力下 Txy/Pxy、相对挥发度，必要时补 LLE/VLLE | 共沸、夹紧趋势、关键组分与压力候选 |
| 三元精馏 | Aspen Ternary Map / Distillation Synthesis 的共沸点与蒸馏边界；相应二元边界作交叉核对 | 内部三元共沸点、蒸馏区域、分离顺序和溶剂/夹带剂候选 |
| 四元及以上 | 选择有依据的关键三元子体系并检查全组分闪蒸/相稳定性，必要时用更高维分析 | 筛选控制分离的组分组合，识别子图不足以证明的部分 |
| 冷凝分层或异相流程 | 在上述分析上补相应温压下液液分相曲线、联结线和 VLLE | 分层器与回流相的候选拓扑 |

**精馏三元图、残余曲线、等温液液三元图是不同成果。** 用户要求共沸点与蒸馏边界时，必须计算相应对象，不能仅给残余轨迹或把普通曲线改名为边界。不要用三个二元共沸点推断内部不存在三元共沸点。

多组分子图应标明被省略组分、组成基准和归一化方式；若使用投影组成 `x'_i=x_i/sum(x_selected)`，保留原组成及被选组分总占比。投影后的点只是位置表示，不能假设省略组分不影响活度、共沸或分相，更不能据子图宣称整个多组分流程可分。

## 3. 把相图变成搭塔依据

1. 在与方案一致的压力、物性和相数下，标出实际进料及候选产品点，记录共沸点、边界及来源。简单单进料、两产品、无反应/侧采且同一组成基准时，检查 `zF=(D/F)*xD+(B/F)*xB`；有循环、多进料或分层时按实际节点衡算，不强套一条直线。
2. 比较普通精馏、分离顺序、压力方案，以及任务允许的萃取/共沸/分相流程。变压要在各候选压力下重新计算共沸位置与边界，并同时检查参数范围、冷凝温位和再沸温度；不能只凭两塔压力不同决定采用变压。
3. 明确哪些限制来自相平衡、哪些来自图所对应的轨迹和操作假设。不能把某条蒸馏边界直接宣称为所有有限回流、侧线、反应、分相回流或变压构型的绝对限制；可疑方案需对应构型的进一步分析与严格模拟。
4. 输出可检查的决策记录：图型/版本/工况与组成基准；物性证据及缺口；进料/候选产品与边界关系；选用/排除路线及理由；进入严格塔的参数候选和未解决问题。**画图后仍按原猜测盲目加板、调回流，不算完成应用。**

## 4. 从相图进入严格塔

- 将分离路线、关键组分、压力候选、冷凝/再沸方式及必要的分层/溶剂回收步骤落实到方案。只有适用时才用 DSTWU 初估；强非理想、共沸或多夹紧不能无条件套简捷法。
- 在同一物性与产品/回收率约束下，用 RadFrac 等适用严格模型扫描级数、进料位置、回流及溶剂比。进料状态/焓、MESH、自由度和有效收敛点共同决定参数；三元图不直接给出最终板数、进料板、回流比或塔径。
- 关键物性、压力、溶剂或进料范围改变后，重新核查相关相图与判断。最终仍需最新运行证据、独立衡算、相态、冷启动及水力验证；不得放宽容差或用指定组分分配替代分离能力验证。
- 缺少热力学证据时，只能交付明确边界的探索模型，不能以图形、数值收敛或包校验代替物理验证。严格塔原则见[精馏与塔器](textbook-distillation-and-towers.md)。

## 5. Aspen Plus V14 原生 Ternary Map 的已核验机制

以下是本机 V14 的接口经验，不是跨版本保证，也不是某套物性对所有体系的推荐。计算可通过原生界面或经当前版本核验的自动化完成；若接口不可用，应报告具体缺口，不能换成残余曲线宣称完成。

- 从已核验的源物性工程导出原生属性包；`Apwn.Document.Export(20, path)` 在本机生成 `.aprpdf`，可供 `InitFromAppdfFile` 使用。核对实际输出文件名与哈希；源物性工程不自动包含已保存的三元图 GUI 画布。
- 本机 `DistillationAnalysis.exe` 的 `DistillationApp` 可经 comtypes 显式类型库/直接接口调用。晚绑定可能报“库未注册”；无需为绕过该问题修改系统注册表。进程 DLL 搜索路径须覆盖相应 Engine、GUI、OOMF 与 PropertiesDatabase 目录，使用已核验的许可环境。
- 先加载属性包，再取得 `GetDistillationMap()`，按当前模型设置组分、方法、相数和压力；本接口压力为 Pa、温度为 K。组分 ID、顺序和相数代码以本机类型库/方法核验为准，不把示例值当作当前模型设置。
- **已核验的调用次序是 `GetPureProperties()` → `GetAzeotropes()` → `GetDistillationBoundary()`。** 缺少第一步可使后续调用失败。`GetResidueCurve()` 是另一种计算，不能替代边界调用。完成后关闭包并归还许可，异常路径也要清理。
- 保留实际闪蒸容差和迭代上限，修改只允许保持或收紧，并记录前后生效值；不机械照抄接口缺省迭代上限。闪蒸容差与共沸搜索坐标精度分别核验。
- 原生边界数组可能包含 `[-1,-1,-1]` 填充；按有效组成校验剔除，同时保留原始输出。区分三角形边段和内部边界。曾遇到未初始化的纯端点坐标矩阵，不可直接用于绘图；纯组分顶点可按组成定义设置，并说明来源。

## 6. 相图验收与交付边界

- 保存源物性/参数来源、压力与相数、坐标顺序/基准、原始共沸点与边界数组、有效导出数据、状态码及求解设置；独立重建组件/重载包复算。重复一致只证明数值复现。
- 对决定路线的共沸点，另做同压泡点/微小气化率闪蒸等核对。均相共沸检查温度与 `y_i≈x_i`；有限气化率要注明，判据按任务精度确定。非均相共沸须核对 VLLE 及两液相/总体组成关系，不能要求每个液相都等于蒸汽组成。
- 原生搜索坐标若有可见残差，报告并在相同模型中精化；同模型交叉求解不能称作独立实验验证。精化点与原生边界的数据身份保持清楚，不悄悄拼接出未经计算的新边界。
- 原生组件未生成 `.his` 时，明确采用何种状态/复算证据；不得拿其他物性表或旧流程的日志冒充。重绘应标为“原生数值重绘”，只有实际检查到 GUI 保存结果时才能声称已在 Aspen 画布显示。

来源边界：工程判断承接上述 M01/M02 教材条目；接口机制来自本机 Aspen Plus V14 类型库、原生界面调用顺序与独立组件复算。概念设计定位参见 [Aspen 官方精馏建模学习指南](https://www.aspentech.com/en//-/media/aspentech/home/cst-certification/aspen-plus-certification/at-05198_aspen-plus-dm-study-guide)。这些证据不构成任意新体系的实验物性验证。
