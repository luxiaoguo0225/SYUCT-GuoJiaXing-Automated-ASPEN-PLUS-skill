# 动力学反应器输入流程（动力学反应器模拟实例 320-322）

这份笔记把三篇文章里的输入顺序压成一条可复用流程，重点是“先建反应，再选模型，再挂反应器”。

## 1. 先选反应集类型

- 先建 `Reactions` 集
- 动力学反应优先走 `Kinetic`
- 需要时再在 `Kinetic` 里落到 `General`，然后映射到 `LHHW` 或 `PowerLaw`
- 若文献已经是明确的内置形式，可直接用对应模型

## 2. `PowerLaw` 的输入顺序

- 选 `Reaction type = Kinetic`
- 指定反应相态
- 指定速率基准
- 输入动力学参数 `k`、`E`
- 输入反应级数和浓度基准
- 反应速率常数单位要跟 `kmol`、`sec`、`m3`、催化剂质量/体积基准对应起来

## 3. `LHHW` 的输入顺序

- 选 `LHHW` 反应集
- 根据化学计量先定义反应物和产物
- 在 `Kinetic` 页输入 `k`、`E`
- 在 `Driving Force` 里定义 `Term1`、`Term2`
- 不可逆时，正向项保留，逆向项可令为极小/极负
- 可逆时，两项都按文献式写入
- 若存在吸附机理，再在 `Adsorption` 里定义吸附项；没有吸附影响时可弱化或省略

## 4. 反应器怎么选

- `RCSTR`: 全混釜动力学反应器，适合搅拌釜、液相反应、用体积/停留时间收敛的场景
- `RPlug`: 平推流/填充床动力学反应器，适合管式、固定床、多管反应器
- 反应器本体只负责承载反应集，真正的动力学表达还是在 `Reactions` 里

## 5. 典型落地顺序

1. 输入组分和物性方法
2. 建 `Reactions` 集
3. 先确认反应式和相态
4. 先用 `General` 思路整理文献公式
5. 再选择 `LHHW` 或 `PowerLaw` 落地
6. 把反应集挂到 `RCSTR` 或 `RPlug`
7. 再用设计规定/体积/停留时间/转化率去收敛

## 6. 文章里的两个示例

- 上篇：先讲 `PowerLaw` 和 `LHHW`，再讲 `RCSTR` 与 `RPlug`
- 中篇：以 `LHHW` 的 `Term1`、`Term2`、`Adsorption` 拆解输入方式
- 下篇：`RCSTR` 示例用设计规定调体积，使转化率达到目标
