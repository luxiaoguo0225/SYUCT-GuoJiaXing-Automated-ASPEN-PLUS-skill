# RPlug 原生灵敏度：参数优化的方法与证据边界

适用：已有动力学平推流反应器的参数扫描、优化前部复做，尤其是用户限定“只用 Aspen Sensitivity，并在交付中保留分析”。这是去标识的实现经验，不保存项目模型、原料配方、动力学常数、设备规格、最优点或私有路径。

原理先读 [M03-K01–K03、K07–K09、K13](textbook-reaction-engineering.md) 与 [M08-K05、M09-K01、M14-K03/K04](textbook-numerics-economics-and-custom-models.md)。跨设备的扫描范围及全组合配置见 [Sensitivity 通则](sensitivity-scope-and-configuration.md)。异常处理回到 [M15 专项诊断](../modules/run/diagnostics/rplug-native-sensitivity-fixes.md)，不能仅在报告中列问题后继续宣称工程优化通过。

## 1. 先区分复现、条件寻优与工程优化

| 用户目标 | 实际要做 | 结论边界 |
|---|---|---|
| 学习或复做附件前部 | 冻结阅读范围，保护原件；先比较文档、输入和旧存表，再运行副本 | 说明复现到了哪些设置与数值，不自动开展后部选型、评级或经济核算 |
| 指定范围的条件寻优 | 明确目标、约束及固定量，用有效的原生扫描点筛选 | “其余参数固定时、本网格内”的最优；边界最高点不是内点极值 |
| 工程/经济优化 | 除数值外，闭合动力学、物性、压力/热量、设备约束及成本边界 | 只有相应必需证据闭合才可给工程推荐；不能用扫描图替代缺失依据 |

文档选定点可能是折中或设计决定。曲线单调且没有成本/约束时，不把设计点称为数学最优，也不把范围端点称为已求得有限最优尺寸。不同单变量曲线的最高点不能直接拼接成联合最优组合。用户需要联合作用时，另在授权范围内设置原生多变量全组合并检查真实行数。

## 2. 扫描之前审计“实际生效的模型”

- 记录串联各床层、再热器及流股的实际连接。确认变化的是第一段入口、全部入口还是冷却介质温度；上游温度改变后，受独立加热器控制的下一段入口可能仍固定。
- 回读每台反应器实际连接的反应集。档案中存在多个动力学集合，不代表它们都参与计算；避免把未连接集合的单位或常数当成活动速率式。
- 对活动反应逐项核反应相、速率基准、浓度/分压或逸度基准、压力单位、时间单位、Arrhenius 参考温度及活化能单位；检查每个反应，不能由前一行的单位推定整组。
- 先把活化能换算到相同量纲，再对照来源。不同单位本身不证明错误；相同数值配不同单位可能代表不同物理量。来源不全时登记疑点，不擅自“统一单位”后冒称原样复现。
- 检查整个床层的温压、组成及催化剂条件，而非只看入口是否落在动力学适用范围。非等温床层可能在轴向离开声称的适用温区。
- 读取的是标量叶节点及其单位。COM 容器的 `Value` 可能是表标记；例如流股的总质量或焓流需到对应子流股叶节点，而不是把容器值当作结果。

遇到跨版本库引用导致组分不完整，先按 [M15](../modules/run/diagnostics/rplug-native-sensitivity-fixes.md#version) 查证；“界面能打开”不能替代输入完整或物性有效。

## 3. 自变量应对应真实的模型边界

| 参数 | 可用的原生 Vary 方式 | 必须同时核对 |
|---|---|---|
| 入口温度 | 进料 STREAM-VAR/TEMP；或控制实际入口的 Heater BLOCK-VAR/TEMP | 实际反应器入口、后床再热设定、加热与冷却负荷 |
| 入口压力 | 优先变化进入研究边界的流股 STREAM-VAR/PRES，使下游按规格继承 | 全链压力及压力恢复机制；不要把 Heater 指定升压当作已计算压缩功 |
| 进料比 | 固定作为分母的原料流量，变化另一组分的 MOLE-FLOW，并在 Tabulate 输出实际比值 | 是固定反应物处理量还是固定总流量；组成、热容、体积流量和停留时间会同时变 |
| 反应器体积 | 原生支持的尺寸参数，如 BLOCK-VAR/LENGTH 或 DIAM，并表列几何体积 | 单管/多管及直径定义、空隙率、有效体积、管数、催化剂量/密度、传热面积是否联动 |
| 压降 | 在已核语义的 RPlug 压力规格模式中变化压降，或采用有依据的压降关联式 | 规格符号、实际单位、正的绝对出口压力、沿程路径及是否与尺寸/流量耦合 |

单圆柱名义体积为 `πD²L/4`；多管需按本模型的管数和尺寸定义处理，不能直接当催化剂体积。`REAC-VOL` 与 `CAT-WT` 对几何和装填变化的响应不同，看到 CATWT 字段存在并不证明它直接缩放当前速率。

固定指定压降的 L/D/配比扫描只回答这一假设下的反应响应，不验证真实床层水力变化。负号代表压降的语义只适用于已核对的规格模式，不可推广到所有模块。1D RPlug 的尺寸曲线不能证明径向均匀性、死区或径向温差已通过校核。

## 4. 让目标和评价指标留在原生分析里

用户限定只用 Sensitivity 时：

- COM/MCP 可以设置 Define、Vary、Tabulate、触发运行、读表和存档；所有扫描工况由 Aspen Sensitivity 生成与计算。
- 不用外部逐点改参重算、NSGA-II 或其他优化器代替扫描；不用事后写回结果补齐原生表。除非任务另有授权，不引入 Calculator/Design Spec 搜索或改变模型。
- 可以从原生结果做筛选、比较、提取 CSV 和外部绘图，但要标明来源是 `SNS_TAB`；外部图不是 Aspen 原生 Plot Wizard 图。

设反应物为 A、目标产物为 P，化学计量为每摩尔 A 最多生成 `ν` 摩尔 P：

```text
X_A = (F_A,in - F_A,out) / F_A,in
Y_P,net = (F_P,out - F_P,in) / (ν * F_A,in)
S_P,net = (F_P,out - F_P,in) / (ν * (F_A,in - F_A,out))
```

对应进料量或净消耗接近零时，显式处理指标无定义的点，不能除零或将其作为最佳选择性。对于其他反应网络或元素基准，先重定义指标及计量关系。

入口已有目标产物时必须扣除入口量。`F_P,out/F_A,in` 不能直接标成选择性。多床整体指标以整体反应段入口/出口为边界，单床指标另命名；单程转化不等于全流程新鲜原料总转化。

建议同时表列目标产物量、转化率、净产率、净选择性、实际进料比、各床出口温度、末端压力、名义体积及相关热负荷。通过原生 Tabulate 表达式或分析内部 Fortran 计算，保留其定义；无需为了简单指标增加全局 Calculator。

热负荷采用明确边界。已高温汽化的进料不包含其制备热；两个 Heater 的有符号净负荷不等于燃料费用、供汽成本或全部公用工程。压力变动引起的上游压缩/真空功耗也不能凭空计入或省略后称经济最优。

## 5. 原范围复现 → 有界细化 → 单点保留

1. 原设置先独立跑通；保存本次历史、实际容差、活动对象及原生表。对照文档截图、附件旧存表与新运行三套来源，不能将旧存表冒充本次计算。
2. 在已核可用范围内做条件响应。温度/尺寸变化若改善产量同时降低选择性或增加负荷，按多指标解释折中；不替用户新增约束来“满足”原目标。
3. 仅在确有内点峰值或关键约束附近做原生细扫。峰顶变化与数值误差同量级时，报告近似区间；如需更精细结论，收紧相关积分容差或改变网格验证，并记录实际设置。不得放宽容差。
4. 有需要时另存固定所选点的模型，并保留单点 Sensitivity：基准设定与单点 Vary 坐标一致，重算后比较该行与扫描中的对应行。不要在“单点文件”里悄悄继续其他参数搜索。

Aspen 可能自动插入不在网格内的基准点，基准甚至可能位于细扫区间外。按自变量坐标识别基准、设计点与最优点，不假定首行、末行或固定行号。全组合行数计算要明确是否含插入基准、重复坐标和失败行。

## 6. 结果到交付的检查

- 从真实原生表读取值、列头和单位，以当前格式已验证的 `ROWSTAT=0` 识别成功行。保留失败行及失败原因，筛选时剔除失败或违反约束的点，不能将它们连成正常曲线。
- 检查导出列头/单位；Vary 的输入显示单位可能与结果列不同，列标签也可能被截短。保存原始列头映射，不能靠列位置或截图猜单位。
- 在新目录、新 COM 进程打开冻结候选，Reinit 后重新执行原生分析。按分析名、自变量坐标和实际结果列比较；数值容差采用适合该问题的依据，不把本次恰好完全一致规定为所有项目必须逐位相同。
- 用输入完整性、实际运行状态、完整新历史以及成功行共同确认执行。完整日志尚未落盘时，不能凭截断内容认定无错误。相关取证与保存陷阱见 [M15](../modules/run/diagnostics/rplug-native-sensitivity-fixes.md#history)。
- 对设计点另核进出质量、必要元素及能量闭合；有反应时不能用总摩尔流量相等代替守恒。图形可见性与数据正确性分开检查。
- 原生分析对象、变量定义、扫描范围、结果表及单点均应可编辑保留。冷重开要针对实际交付字节；界面另存或候选修改后需更新相关复算/身份记录。
- 通过 [O01/O02](../modules/output/index.md)：输入/运行/存盘问题回 M09/M15，单位/动力学回 M03/M01，边界或压降回 M04/M05，目标与精度回 M08/M14。物理必要项未闭合时保留具体未验证项，不用数值复现通过替代工程验证。

## 可迁移证据与限制

本机历史操作核实过原生单变量扫描、局部细扫、分析内部指标、基准插入、单点保留、归档读回及独立重开比较机制。历史过程中也发现文档与存表不一致、活动反应单位疑点和固定压降不随尺寸变化等问题。前者是实现机制证据，后者是待审计问题类型；均不认证其他反应体系的动力学、物性、催化剂、工业尺寸或最优参数。
