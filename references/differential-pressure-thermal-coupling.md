# 热耦精馏与差压热耦合（文章总结 + Aspen 建模映射）

> 来源：微信公众号文章《精馏节能技术——热耦精馏》（2026-08-31 学习整理）
> 用途：热耦精馏（Petlyuk/DWC）适用性判断、差压热耦合（两塔变压 + 蒸汽再压缩热泵）建模要点、C3 丙烯/丙烷节能案例数字
> 关联：`thermally-coupled-distillation.md`（Petlyuk/DWC 双塔等效建模细节）、`column-splitting-and-heat-integration.md`（拆塔 + HeatX）、`double-effect-*`（HeatX 热集成 + DESIGN-SPEC 工作流）

## 0. 一句话要点

- 常规精馏冷/热流体传热不可逆、需要温差 → 温差越大有效能损失越大、热力学效率越低。
- 热耦精馏：副塔不用冷凝器/再沸器，靠主塔汽液耦合流驱动，节能 20%~40%（A/B 与 B/C 相对挥发度相当、B 为主组分、泡点进料、产品 90% 纯度时约 20%）。
- 差压热耦合：把单塔分割为常规分馏塔 + 降压分馏塔，用一台压缩机实现"常规塔顶汽潜热加热降压塔再沸器"的完全热耦合，能耗只剩压缩机动力（C3 实例 -92.3%）。

## 1. 热耦精馏（Petlyuk/DWC）适用性（文章的 4 条限制）

1. **产品纯度**：中间产品需高纯度时才值得用；纯度要求不高直接常规塔侧线采出即可。
2. **进料组成**：进料中组分 B（中间组分）量应最多，A 与 C 量相当。
3. **相对挥发度**：α(A/B) 与 α(B/C) 相当时节能优势最明显；若 A/B 远比 B/C 好分离，不如常规双塔。
4. **操作压力**：整个分离过程压力不能改变；需变压时只能用常规双塔流程。

工程经验（已验证 2026-08-27 苯/甲苯/乙苯）：热耦对主副塔汽液分配偏离非常敏感，分离越难越难操作；只有沸点接近、易分离物系才推荐。具体 Petlyuk 双塔等效建模见 `thermally-coupled-distillation.md`。

## 2. 差压热耦合低能耗蒸馏（文章第二部分，天津大学技术）

### 2.1 流程结构
- 常规分馏塔：操作压力与常规单塔相同（高压塔）。
- 降压分馏塔：降压操作降低塔底温度，使塔底温度 < 常规塔顶温度。
- 常规塔底液相 → 降压塔顶（差压推动）。
- 降压塔顶汽 → **压缩机**加压 → 常规塔底部作上升蒸汽。
- 常规塔顶汽 → **主换热器热侧**，加热降压塔底再沸液（冷侧）→ 部分汽化形成再沸蒸汽；同时常规塔顶汽得到部分/全部冷凝液。
- 负荷匹配：
  - 冷凝负荷 < 主再沸器负荷 → 开**辅助再沸器**；
  - 冷凝负荷 > 主再沸器负荷 → 开**辅助冷凝器**（冷凝液进回流储罐，一部分回流、一部分产品采出）。

### 2.2 优点
- 常规塔顶冷凝负荷与降压塔底再沸负荷匹配换热 → 完全热耦合；
- 用差压降温实现最小热消耗，甚至冷热负荷完全匹配、热消耗为零；
- 只增加一台压缩机，动力消耗远小于被替代的热消耗。

### 2.3 C3 丙烯-丙烷节能实例（关键数字）
- 难点：沸点接近、相对挥发度小 → 常规塔高达 90 m、200+ 块板、RR>10、需加压或制冷，能耗极大。
- 常规方案对比：
  - 高压法：塔顶 >45℃ 可用冷却水，但塔板多、回流比大；
  - 低压法：相对挥发度大、板数/回流比小，但塔顶温度太低需其他冷剂（投资+能耗增加）；
  - 热泵法：节能最高 70%+，但投资 +20%、流程复杂操作困难。
- 条件：进料 16832 kg/h（约 15 万吨/年）、40℃、丙烷 25.8 wt% / 丙烯 74 wt% / 乙烷等 0.2 wt%；塔顶丙烯 >99 wt%。
- 常规流程：200 块理论板、进料第 146 块；塔顶 43.4℃ / 1800 kPa；塔底 58.7℃ / 2100 kPa；热耗 6.39×10^7 kJ/h。
- 差压热耦合：常规分馏塔 145 块 + 降压分馏塔 55 块，进料在降压塔适当部位；仅压缩机动力 4.92×10^6 kJ/h。
- **总能耗降低 92.3%**（热耗全部被压缩机动力替代）。

### 3.2 差压热耦合 → 两塔变压 + 蒸汽再压缩热泵
- 结构 = 跨塔蒸汽再压缩：降压塔（低压）顶汽 → 压缩机（ASME 多变）→ 高压塔底部；高压塔顶汽 → HeatX 热侧，降压塔底再沸液 → HeatX 冷侧（主换热器）；负荷不匹配加辅助 Heater/再沸器。
- 模板：`assets/column-split/styrene_heatpump.inp`（拆塔 + 蒸汽再压缩热泵）。
- 要点（沿用技能已验证规则）：
  - 再沸汽撕裂流初值给**高于露点**（全汽相），回流液初值给**低于泡点**（全液相），否则 UDL03.4xxx 干板/相态错；
  - HeatX 完整指定 `PRES-HOT=... PRES-COLD=...`（负值=压降），不写 `HOT-SIDE ... DP=`（2041）；
  - 压缩机压缩比扫参并检查 HeatX 整体/分区 LMTD 与最小接近温差，**压缩比 ≤ 2.5**；
  - 压力场：普通正压服务 -0.2 bar 起步，真空/低压回路才用 -0.01~-0.05 bar；不加补偿泵；
  - 温度敏感组分优先检查（苯乙烯 >100℃ 聚合）：热泵会过热升压汽；差压热耦合用**降压降温**，对热敏体系更友好，仍要做全流程温度清单核对；
  - 撕裂流 BROYDEN + 相态初值 + flowsheet DESIGN-SPEC（先收敛一个再叠第二个，LIMITS 收紧）。

### 3.3 能耗对比口径（验收）

  - 差压热耦合 = 压缩机功率（+ 辅助再沸器/冷凝器净热耗，若存在）；
