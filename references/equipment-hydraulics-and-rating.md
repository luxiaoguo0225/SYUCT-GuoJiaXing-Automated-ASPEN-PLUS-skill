# 设备水力学、压降与评级边界

## 1. 适用范围

本文件补充 Aspen Plus 流程完成后的设备水力学检查。它覆盖两类任务：

1. **与水力学直接相关的工艺筛选**：塔径、有效面积、管内流速、泵功率、NPSH 差值、阀门压降初筛、换热器允许压降。
2. **将 Aspen 工况送回设备模型后的证据检查**：塔板或填料负荷、液泛裕量、压降回路、设备限制和流程复算。

该流程不替代真实塔内件评级、厂家选型、完整管网水力学、瞬态水锤、管道应力、机械设计或商业软件验收。

## 2. 证据等级与结论措辞

每次水力学工作必须先标记结论等级：

| 等级 | 依据 | 可以表述 |
|---|---|---|
| `PRELIMINARY` | 流程体积负荷、目标流速或初设几何 | 初估、筛选、待核 |
| `SOURCE_BOUND` | 公式、关联式、标准或厂家限值均有来源 | 按指定来源计算，适用范围内通过 |
| `ASPEN_EVIDENCE` | 同一 Aspen 工况导出的压力、相态、流量和物性 | Aspen 工况一致，软件结果已读取 |
| `VENDOR_RATING` | 塔内件、泵、阀门或换热器厂家同工况数据 | 厂家评级或选型确认 |
| `CLOSED` | 工艺、设备、压力和机械接口全部闭合，且原始文件可复开复算 | 该检查范围闭合 |

禁止把 `PRELIMINARY` 或 `SOURCE_BOUND` 结果写成最终设计通过。任何“通过”必须同时给出：

- 使用的公式或关联式；
- 适用相态和物性基准；
- 单位制；
- 控制工况；
- 允许限值的来源；
- 尚未闭合的项目。

## 3. 输入冻结

在计算前冻结以下内容：

- 设备位号和物理服务；
- 正常、最小、最大、开工和扰动工况；
- 气相和液相流量，质量流量与摩尔流量分开记录；
- 温度、压力、密度、黏度、表面张力；
- 是否发生相变、闪蒸、冷凝或溶解；
- 设备和内件几何；
- 设计压力和设计温度；
- 允许压降和下游压力裕量；
- 设备与管道材料、腐蚀裕量和污垢基础。

若 Aspen 中 `HYDRAULIC=NO`，干净收敛只证明当前物料和能量计算，不证明塔板或填料水力学通过。必须从同一最终工况导出阶段负荷和物性，再进行水力学检查；任何塔径或内件修改后都要重新运行 Aspen。

## 4. 塔器水力学

### 4.1 负荷工况

至少检查：

- 正常负荷；
- 最小负荷或最小回流；
- 最大负荷；
- 开工和停机相关工况；
- 高液相或高气相偏负荷；
- 压力和温度上、下限。

对每个控制塔段保留相同的相态、组分、单位制和几何基准。不得用全塔平均负荷直接定塔径。

### 4.2 面积闭合

必须显式闭合：

```text
A_total = A_active + A_downcomer + A_receiving + A_inactive + A_other
```

初设阶段可用：

```text
A_active = A_total * (1 - f_downcomer - f_receiving - f_inactive - f_other)
```

该式只用于几何初筛。实际塔板布局、堰、支撑圈、边缘区和多溢流流型确定后必须重算。

### 4.3 塔板检查项

塔板水力学至少包括：

- 阀孔、筛孔或浮阀开孔面积和开孔率；
- 堰长、堰高、板上液层和液流强度；
- 降液管面积、停留时间和降液管背压；
- 干板压降、液层压降和残余压降；
- 雾沫夹带；
- 漏液或排液；
- 液泛裕量；
- 各控制段的正常、最小和最大负荷包络。

基本速度关系：

```text
u = Q / A
F = u * sqrt(rho_v)
```

其中 `u` 的速度面积基准必须写清：全塔截面积、有效鼓泡面积或填料截面积。`F` 只能与相同基准的泛点因子比较。

液泛率可写为：

```text
flood_fraction = F_actual / F_flood
```

`F_flood` 必须来自适用的关联式、塔板图、厂家数据或经验证的计算模型，不能凭习惯常数设定。漏液、夹带和压降同样需要各自的适用关联式，不得由液泛率单独推导。

### 4.4 填料检查项

填料塔至少检查：

- 气相负荷因子或泛点率；
- 填料湿润和液体分布；
- 液体喷淋密度；
- 每段填料压降；
- HETP 或 HTU-NTU；
- 填料床层高度和分段；
- 液体收集器、再分布器及支撑结构；
- 气体和液体偏流；
- 减少或增加负荷时的稳定性。

若采用理想气体密度进行初筛，必须明确这是 `PRELIMINARY`。正式计算应从同一 Aspen 工况读取真实相密度，或使用经过验证的状态方程。

### 4.5 压力反馈

把以下压降合计并反馈到流程模型：

- 塔内件；
- 填料或塔板；
- 分布器和收集器；
- 除沫器；
- 管口和连接管；
- 静液柱；
- 控制阀及其他真实阻力。

当回流比、进料位置、塔径、塔压或内件改变时，必须重跑 Aspen 并重新生成同工况水力学证据。

## 5. 管道、泵和阀门

### 5.1 管道初筛

给定体积流量 `Q` 和目标流速 `v`：

```text
A = Q / v
D_i = sqrt(4 * A / pi)
```

选定标准管内径后：

```text
v_actual = Q / A_selected
```

这些结果只解决管径和基本流速筛选。完整管道压降至少还需要：

- 管长、粗糙度和高程；
- 管件、阀门和仪表；
- 密度、黏度和雷诺数；
- 沿程阻力与局部阻力；
- 多相流型；
- 可压缩性和闪蒸；
- 水锤、瞬态和管道应力。

没有这些输入时，不能声称完成完整管网校核。

### 5.2 泵

基本功率关系：

```text
P_hydraulic = rho * g * Q * H
P_shaft = P_hydraulic / eta_pump
```

汽蚀初筛：

```text
NPSH_margin = NPSHa - NPSHr
```

正向裕量不等于通过。必须确认：

- `NPSHa` 和 `NPSHr` 处于同一流量、转速、温度和介质；
- `NPSHr` 来自同工况厂家曲线；
- 裕量满足项目规定或适用标准；
- 吸入管压降、液位和汽化压力已纳入。

### 5.3 阀门

液体、气体、蒸汽和两相阀门不能用同一个简化公式代替。至少保留：

- 介质相态和是否闪蒸；
- 正常、最大和最小流量；
- 入口压力和出口压力；
- 允许压降；
- DN、压力等级、材料；
- `Cv` 公式及单位基准；
- 阻塞流、汽蚀、噪声和执行机构检查。

只有公式、单位和厂家曲线属于同一适用域时，才能把 `Cv` 结果作为正式选型依据。

### 5.4 换热器

区分：

- Aspen `HeatX` 的热侧和冷侧压降；
- `HeatX Detailed`；
- `Shortcut`；
- 真正的 Aspen EDR 评级；
- 厂家热工和机械数据。

EDR 模型必须确认执行身份、输入路径、负荷、面积裕量、压降、速度和材料依据。干净流程日志不能替代换热器评级。

## 6. Aspen 与外部接口

水力学检查可以使用三种手段：

1. 本 Skill 的初筛计算；
2. Aspen 原生塔内件或换热器模型；
3. 经授权的本地 COM、EDR、厂家模型或独立验证脚本。

无论采用哪种方式，都必须：

- 绑定同一工况和同一模型版本；
- 记录输入和输出的单位；
- 保留来源、哈希或文件身份；
- 在修改塔径、压力、内件或回路后重新计算；
- 将设备限制反馈到流程并再次运行 Aspen。

## 7. 输出模板

```text
设备：
任务和物理服务：
结论等级：PRELIMINARY / SOURCE_BOUND / ASPEN_EVIDENCE / VENDOR_RATING / CLOSED
控制工况：
采用方法及来源：
输入与单位：
计算结果：
允许限值及来源：
检查：
未闭合项：
需要重跑的 Aspen 块或流股：
原始文件身份：
```

如果输入不足，应只计算闭合的部分，并明确列出最小缺项，不得填零或默认通过。

## 8. 初筛脚本

`scripts/hydraulic_screening.py` 只实现透明的初设算术：

- 塔初步直径、总面积、有效面积和速度/F 因子；
- 管道需求内径和选定内径下的实际流速；
- 泵水力功率、轴功率和 NPSH 差值。

脚本不包含塔板或填料的经验关联式，不输出最终通过结论。正式塔内件水力学仍需适用关联式、Aspen Column Internals、厂家数据或独立验证方法。
