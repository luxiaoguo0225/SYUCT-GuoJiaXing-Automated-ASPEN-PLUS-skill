# 天大《化工原理》下册 9.5：两组分连续精馏计算与优化

> 来源口径：用户指定的天津大学《化工原理》下册第 9.5 节“两组分连续精馏的计算”
> （9.5.1 基本假定、9.5.2 物料衡算与操作线、9.5.3 理论板层数、9.5.4 回流比、
> 9.5.5 简捷法、9.5.6 特殊情况）。本文只提炼原理、公式和工程执行方法，不复制教材原文。
>
> 适用范围：恒压、恒摩尔流、近理想两组分或可用分段平均相对挥发度近似的体系。
> 多组分、强非理想、共沸、三相、反应精馏、显著热效应或非恒摩尔流必须用 rigorous
> RadFrac 复核；本文结果只能作为初值和搜索范围，不能代替严格模拟。

## 1. 先把“适宜”与“最优”分开

- 教材 9.5.4 的“适宜回流比”是**经济权衡后的工程推荐值**，不是单一数学极值。
- 严格“最优进料状态、最优回流比、最优塔板数、最优进料板”必须同时给出：
  目标函数、约束、公用工程价格、设备年化费用和塔型/水力学边界。
- 若没有完整的费用边界，只能给出：
  - `R_min`、`N_min` 和传质可行区；
  - 满足分离要求的 `R-N-N_F` 可能组合；
  - 经验适宜区间和 Aspen 敏感性/优化搜索范围；
  - 不得把 `1.1R_min`、`q=1` 或某一组经验塔板数宣称为普适最优解。

## 2. 全塔物料衡算与产品分配

以易挥发组分摩尔分数表示，进料 `F, x_F`，馏出液 `D, x_D`，釜液 `B, x_B`：

```text
F = D + B
F x_F = D x_D + B x_B
D/F = (x_F - x_B)/(x_D - x_B)
B/F = (x_D - x_F)/(x_D - x_B)
```

所有逐板、回流比和塔径计算都应先固定这些衡算关系。若回收率或产品流率另有规定，
先检查其是否与上述衡算相容，避免在 Aspen 中“回流比扫不出结果”其实是无物料衡算解。

## 3. 进料热状态 q 与 q 线

教材定义：

```text
q = (H_V - H_F)/(H_V - H_L)
```

式中 `H_V`、`H_L` 为进料组成和塔压下的饱和蒸气、饱和液体摩尔焓，`H_F` 为实际进料焓。

| 进料状态 | q | q 线 |
|---|---:|---|
| 冷液 | `q > 1` | 斜率 `q/(q-1) > 1` |
| 泡点液 | `q = 1` | 竖直：`x = x_F` |
| 气液两相 | `0 < q < 1` | 负斜率 |
| 露点蒸气 | `q = 0` | 水平：`y = x_F` |
| 过热蒸气 | `q < 0` | 正斜率且 `< 1` |

q 线（进料方程）：

```text
y = q/(q-1) x - x_F/(q-1)
```

两操作线交点 `d=(x_d, y_d)` 在 q 线上。对精馏段操作线

```text
y = R/(R+1) x + x_D/(R+1)
```

联立得到：

```text
x_d = [x_D(q-1) + x_F(R+1)]/(R+q)
y_d = R/(R+1) x_d + x_D/(R+1)
```

教材的图解法规定：从塔顶开始画阶梯，阶梯跨过两操作线交点 `d` 时切换到提馏段操作线；
交点 `d` 所在的梯级就是**适宜进料板位置**。逐板法对应为：液相组成首次达到或跨过
`x_d` 的那层板进料。

## 4. 操作线方程

精馏段：

```text
L = R D
V = L + D = (R+1)D
y_(n+1) = R/(R+1) x_n + x_D/(R+1)
```

提馏段：

```text
L' = L + q F
V' = V - (1-q)F
y_(m+1) = (L'/V') x_m - (B/V') x_B
```

必须检查 `V' > 0`、操作线不与平衡线交于无物理意义区，且在给定纯度下确有有限板数解。
q 增大时，`V'` 和 `L'` 改变，提馏段操作线移动；这就是进料热状态影响板数和下部汽液负荷的
直接原因。

## 5. 最小回流比

正常平衡曲线下，令 q 线与平衡线的交点为 `(x_q,y_q)`，该点通常就是夹紧点：

```text
R_min = (x_D - y_q)/(y_q - x_q)
```

等价地，精馏段操作线在最小回流时穿过 `(x_D,x_D)` 和夹紧点 `(x_q,y_q)`。

常用特例：

- 泡点进料 `q=1`：

```text
x_q = x_F
y_q = y*(x_F)
R_min = (x_D - y*(x_F))/(y*(x_F)-x_F)
```

- 露点进料 `q=0`：

```text
y_q = x_F
x_q = x*(x_F)
R_min = (x_D-x_F)/(x_F-x_q)
```

对强非理想或平衡线有拐点的体系，不能只取 q 线交点。应扫描所有可能夹紧点并取满足
操作线约束的最大 `R_min`：

```text
R_min = max_[valid pinches] (x_D-y*)/(y*-x)
```

若得到负值，说明所选夹紧点已越过塔顶组成，必须回到平衡线几何重新判断，不得把负回流比
当作有效结果。Aspen 中应再以严格塔和物性方法独立确认。

## 6. 全回流、最少理论板数与 Gilliland 简捷法

全回流时 `L/D -> infinity`，两操作线与对角线重合，所需理论板数最少。本项目按 9.5 教材
口径记录：Fenske 式得到的 `N_min` **不含再沸器**；若要把再沸器作为一层平衡级报告，另加 1。

```text
N_min = ln{ [x_D/(1-x_D)] [(1-x_B)/x_B] } / ln(alpha_m) - 1
```

`alpha_m` 为全塔平均相对挥发度；组成变化大时应按塔段取平均，或直接用严格平衡模型。

Gilliland 横坐标：

```text
X = (R-R_min)/(R+1)
```

Eduljee 关联式：

```text
Y = 1 - exp{ [(1+54.4X)/(11+117.2X)] [(X-1)/sqrt(X)] }
N = (N_min+Y)/(1-Y)
```

`X -> 0` 时 `N -> infinity`；`R -> infinity` 时 `N -> N_min`。因此回流比不能取成
`R_min`，也说明“塔板数最少”和“总费用最低”不是同一个目标。

精馏段最小理论板数用于预判进料板：

```text
N_min,R = ln{ [x_D/(1-x_D)] [(1-x_F)/x_F] } / ln(alpha_m,R) - 1
N_R = (N_min,R+Y)/(1-Y)
N_F ~= round(N_R) + 1
```

这里按从塔顶往下编号，总冷凝器不计理论级，再沸器另计；`N_F` 只是简捷初值。最终应在
`N_F-2 ... N_F+2` 范围用逐板法或 rigorous RadFrac 扫塔，选择满足分离要求的最佳位置。

## 7. 回流比的适宜范围与真正最优

教材的经济权衡是：

- `R` 增大：操作费用、冷凝器和再沸器负荷增加；设备费用中的塔高/理论板数下降。
- `R` 减小：塔板数快速增加；接近 `R_min` 时出现夹紧区、板效率和水力学风险。
- 总费用通常在某个 `R` 附近形成较平的谷底，因此工程上取大于 `R_min` 的经验倍数。

天大 9.5 课件给出的实践选取范围（仅作初值）：

```text
R = (1.1 ~ 2.0) R_min
实际生产中使用较多的范围：R = (1.6 ~ 1.9) R_min
```

这不是普适数学最优。严格优化时建立：

```text
min TAC(q, R, N, N_F)
= CRF * C_capital(N, D_column, A_cond, A_reb, trays, ...)
  + C_reb * Q_reb + C_cond * Q_cond + C_feedpreheat * Q_feed + ...
```

约束至少包括：

- `R > R_min(q)`；
- 产品纯度、回收率和物料衡算；
- `q_min <= q <= q_max`，进料温度/压力可行；
- 塔顶/塔釜温度限制和最小传热温差；
- 塔径、泛点率、降液管、压降、堰高/板间距等水力学边界；
- `N`、`N_F` 为整数，不能把连续解的塔板数直接四舍五入后当作已验证设计；
- 改变 `q` 或 `R` 后必须重新确定 `N_F(q,R)`，并将 `q-N_F` 联合扫描，不能固定进料板只扫热状态。

推荐求解顺序：

1. 计算 `R_min(q)`，选出严格大于它的可行搜索区间。
2. 对多个 `q` 和整数 `N`，求满足产品规格所需的 `R`；
3. 在 `N_F` 附近扫描整数进料板位置；
4. 用 TAC 或用户指定目标比较所有可行点；
5. 用严格 RadFrac 和水力学重新校核最优点及其左右邻点。

## 8. “最佳进料状态”的工程判断

> **硬规则：进料状态不得一蹴而就。** 在确定最终 `q`、进料温度、压力、`VFRAC` 和
> 进料板之前，必须完成候选状态比较、能量与设备核算、约束筛查，并留下决策记录。
> 只允许把尚未确定的 `q=1` 作为**待验证基准**，不得把经验取值直接写成最终设计规定。

### 8.0 进料状态决策闸门

至少比较以下候选状态；不适用的候选也要给出排除理由：

1. 工艺上游实际给出的进料状态；
2. 泡点进料 `q=1`（无特殊热集成时的基准）；
3. 可利用余热时的热进料或两相进料 `q<1`；
4. 进料源本身为气相时的饱和蒸气 `q=0` 或过热蒸气 `q<0`；
5. 若需要比较冷液路线，也纳入 `q>1` 方案。

每个候选状态必须在同一进料量、同一产品规格和同一压力基准下计算并记录：

| 记录项 | 必须回答的问题 |
|---|---|
| 来源与约束 | 进料是上游液体/气体/两相？压力、温度、热敏、腐蚀、堵塞或安全限制是什么？ |
| 状态参数 | `T_F`、`P_F`、`VFRAC`、`q` 分别是多少？用哪个物性模型计算焓？ |
| 分离可行性 | `R_min(q)`、需要的 `R`、`N`、`N_F(q,R)` 和产品规格是否可达？ |
| 热负荷 | `Q_reb`、`Q_cond`、进料预热/汽化/过热负荷各是多少？净公用工程是多少？ |
| 设备影响 | 塔径、提馏段气相负荷 `V'`、泛点率、压降、再沸器和冷凝器面积如何变化？ |
| 经济与环保 | 年化投资、公用工程费用、总费用、能耗、可用能损失或碳排如何比较？ |
| 稳健性 | 上游波动、控制自由度、负荷调节和开车/停车是否可接受？ |
| 结论 | 为什么选中该状态？为什么排除其他候选？哪些数值来自教材、用户规定或严格物性计算？ |

决策顺序必须是：

1. 先用工艺、安全和设备约束筛掉不可行候选；
2. 再做换热网络和公用工程匹配；
3. 在同一分离任务下比较 `q-R-N-N_F` 的可行组合；
4. 再用用户指定的 TAC、能耗、碳排或操作目标选出候选最优点；
5. 最后用严格 RadFrac、热力学和水力学复核，并验证结果对进料状态扰动是否稳健。

若缺少物性、焓值、公用工程价格或设备边界，只能输出条件性结论和敏感性范围，不能据此宣布某个
进料状态为最终最优。进料状态选择过程必须能在交付物中复盘，不能只留下一个最终 `q` 值。

教材结论是：在固定回流比和分离任务下，q 线交点移动，进而改变提馏段操作线和理论板数；
对正常平衡曲线，q 增大（进料更冷、液相分率更大）通常会使所需理论板数减少，但提馏段
汽液负荷和再沸器热负荷会增加。故不存在脱离费用和约束的单一最佳 q。

### 8.1 基准和热进料判据

- **无特殊余热利用时，泡点进料 `q=1` 是最常用基准**：操作稳定、闪蒸状态明确、
  计算和上下游衔接简单。
- **再沸器负荷紧张或有过剩热源时，可考虑热进料**。这里的“热进料”是指相对冷液
  基准把进料预热，使 `q` 降低，从而降低提馏段汽相负荷 `V'` 和再沸器热负荷。
  必须将进料预热热负荷、换热面积、温位和公用工程价格一并计入，不能只比较 `Q_reb`。
- **若进料本身是气相**，可考虑饱和蒸气或过热蒸气进料，并以其实际可获得的温位和压力
  为准；若需要进一步降低提馏段负荷，应比较预热/过热所耗能量与再沸器减少量。
- 对液体进料，把进料从冷液预热到接近泡点，通常可降低 `V'` 和再沸器负荷；是否继续
  汽化到两相或饱和蒸气，则必须由完整能量、设备和水力学目标决定。

### 8.2 热力学匹配

最佳热状况通常使**进料温度接近进料板的泡点温度，进料相态与进料板处的气液流率和
组成尽量匹配**，以减少进料与板上物流混合造成的不可逆损失。这里的“接近泡点”是对
液相进料的热力学匹配基准，不是对任意物系、任意目标的全局最优断言；气相进料应以其
露点/过热状态和进料板实际条件做同样匹配。

工程决策还应先问：

- 进料在工艺上游本来就是液体、气体还是两相？
- 预热、汽化、压缩或冷却由哪一路公用工程提供？
- 目标是最小化再沸器热、总公用工程、`火用`损、碳排还是 TAC？
- 是否受热敏温度、最低/最高压力、压缩机能力、换热网络夹点限制？
- 改变 q 后，塔径、再沸器面积、冷凝器面积、进料板和产品纯度是否仍满足？

### 8.3 必须与进料板联合优化

改变 q 会移动 q 线与精馏段操作线的交点 `d`，因此最佳进料板位置 `N_F` 也会改变。
不能固定一个经验进料板后单独扫 q；也不能固定 q 后单独扫 `N_F`。严格优化应采用
`q` 与整数 `N_F` 的二维（再叠加 `R`、`N`）搜索，并在最优点附近做严格塔和水力学复核。

## 9. Aspen Plus 落地流程

1. 建立正确的组分、物性方法和进料衡算，确定 `q` 对应的进料 `T/P/VFRAC` 状态。
2. 先用 `DSTWU` 或本文脚本取得 `R_min`、`N_min`、初估 `N` 和进料板，仅作初值。
3. 用 `RadFrac` 严格建立塔，指定初估 `N`、`N_F` 和略大于 `R_min` 的回流比。
4. 用一个设计规定锁定产品纯度/回收率；操纵变量优先用与衡算稳定相关的流量类变量。
   若同时优化 `R` 和 `q`，至少需要与自由度数目一致的独立规定，且不要过规定。
5. 先做敏感性：
   - `R/R_min` 从 1.1 扫到约 2.0；
   - `q` 或进料温度、`VFRAC` 扫描；
   - 对每一个 `q` 和 `R` 重新扫描整数 `N_F`，不要固定进料板；
   - 对整体再做整数 `N` 与 `N_F` 的二维筛选；
   - 每次读取 `Q_reb`、`Q_cond`、预热负荷、塔径/泛点、温度剖面和产品规格。
6. 把 TAC 或用户指定目标交给 Aspen `Optimization`、Calculator/Design Spec 组合，
   或在外部脚本对离散 `N/N_F` 点做枚举，对连续 `R/q` 点做优化。
7. 最终检查 `.his` 为 0 Severe / 0 Error / 0 Warning，并单独核验物料、组分和能量衡算。

DOCX/Excel 中做初步筛选时可用本文脚本；正式 Aspen 结果不得用恒相对挥发度或恒摩尔流假定
替代严格物性与水力学。

## 10. 可复算的数值校验例

取

```text
x_F = 0.50, x_D = 0.95, x_B = 0.05, alpha = 2.5, q = 1
```

则

```text
D/F = 0.50
R_min ~= 1.10
若取 R = 1.5 R_min = 1.65：
N_min ~= 5.43 层（按本教材口径，不含再沸器）
N ~= 10.77 层（不含再沸器；整数化约 11 层，另计再沸器为 12 层平衡级）
N_F ~= 6（简捷估算与恒 alpha 逐板法一致）
```

此例用于校验公式与脚本，不代表任何实际物系或项目的最优设计。

## 11. 配套脚本

`scripts/binary_distillation_9_5.py` 对恒相对挥发度、恒摩尔流的二元体系执行：

- 物料衡算；
- `q` 线、操作线和进料板几何；
- `R_min`；
- Fenske/Gilliland `N_min`、`N`、进料板初值；
- 逐板 McCabe–Thiele 校核；
- `q` 或 `R` 扫描。

示例：

```powershell
python scripts/binary_distillation_9_5.py --xF 0.50 --xD 0.95 --xB 0.05 --alpha 2.5 --q 1 --r-factor 1.5 --json
python scripts/binary_distillation_9_5.py --xF 0.50 --xD 0.95 --xB 0.05 --alpha 2.5 --q 1 --sweep-r 0.2 --json
python scripts/binary_distillation_9_5.py --xF 0.50 --xD 0.95 --xB 0.05 --alpha 2.5 --r 1.65 --sweep-q --json
```

脚本输出仅用于初值和范围搜索；Aspen rigorous 结果是最终依据。
