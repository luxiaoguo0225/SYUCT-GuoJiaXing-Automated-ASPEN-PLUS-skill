# 通用建模机制（跨版本方法）

> **文档定位：工具与机制层（中性）**，服从 `SKILL.md` §1 的两级原则：
> - 不改变第一原则。建模决策仍按「用户/题目规定 > 教材原理 > 有据工程判断」排序，禁止臆想；
> - 本文只收录**跨版本通用**的方法与机制，不收录任何特定 Aspen 版本（如 V11）才成立的结论；
> - 涉及 Aspen 树路径、节点名、端口名、单位或 API 处，**一律以本机安装版本的实测与官方帮助为准**。从其他版本或他人文档看到的"具体单位 / API 可用性"结论不得当作通用事实直接套用，采纳前用 `general-verification-methods.md` 的标定方法在本机版本上确认。

## 1. "达标"类任务的策略三选一（先决策，再动手）

接到纯度/回收率"达标"任务，先按下面三选一确定路线，避免盲目扫参（原理基础：物料衡算 + 相平衡）：

| 情形 | 策略 |
|---|---|
| 双纯度（塔顶塔底都要 ≥ 某值）、体系无共沸、目标可达 | **物料衡算先钉 D/B**：按目标纯度列组分衡算解出塔顶采出 D（与塔底采出 B），把 D/B 作为给定值钉死；分离能力给足裕量——塔板数、进料位置、回流比按体系相对挥发度与进料组成用教材方法估计（**不照抄任何案例数值**）；一次运行后**同时读两侧纯度**，不达标再按预置档位加裕量，首档达标即停 |
| 单纯度且在可达区间内 | 用**设计规定 Design-Spec** 一次求解；操纵变量优先选与物料衡算直接挂钩的流量类变量（如塔顶采出摩尔流量），避免选对收敛不敏感或会破坏进料闪蒸稳健性的变量 |
| 目标超共沸/热力学极限 | 先用相平衡判断上限（共沸组成、相对挥发度极限），直接说明"该纯度在此体系不可达"，**不要扫参** |

通用要点：
- **调参前先做物料衡算预判**。塔顶采出 D 常被进料中轻组分总量"钉死"，在 D 无解或被钉死的区间扫回流比没有意义。
- 档位升级要预置，每档读塔顶与塔底两侧结果，避免只盯一侧。

## 2. 物性方法选型决策树（通用，与教材指南配套）

用户没指定物性方法时，按组分与温压范围用以下决策树自选（命中即停；依据见 `aspen-plus-textbook-guide.md` / `engineering-modeling-basics.md`；禁止默认 NRTL 或反复问用户）：

1. 含电解质/离子/盐/酸碱水溶液（电离/中和/沉淀/胺盐/金属离子）→ ELECNRTL；气态酸性/碱性组分 → ENRTL-RK。
2. 聚合物/低聚物/聚合体系 → POLYNRTL（高密度/超临界段 POLYSL；Flory-Huggins 用 POLYFH）。
3. 高压气体/天然气/炼厂气/低温轻烃/超临界（含 N2/O2/CH4/C2/C3/H2/CO2 等，约 >10 bar 或低温）→ PENG-ROB 或 SRK；含 H2/CO 倾向 PR；水+烃强极性高压 → CPA。
4. 常压极性非理想液体（醇/水/酮/酯/羧酸/酚/芳烃，含共沸或部分互溶）→ NRTL；气相缔合 → NRTL-HOC；液液部分互溶 → NRTL 或 UNIQUAC。
5. 强非理想但缺二元交互参数 → UNIFAC（基团贡献）兜底。
6. 原油/石油馏分/常减压 → BK10。
7. 接近理想、轻组分、教学/简单气液平衡 → IDEAL 或 RK-SOAVE。
8. 固体/无机物/冶金热化学 → SOLIDS 或 FACT。

交叉验证依据（教材原理）：氢键组分（—OH/—COOH/—NH2/水）→ 活度系数法；无氢键烃/永久气体 → 立方型或理想；高压低温 → 立方型（PR/SRK/CPA）；有共沸/液液分相 → 非理想模型，**禁用 IDEAL**；罕见组分缺参数 → UNIFAC。

兜底：组分也没给、无法判断体系时，先向用户要「组分清单 + 温度/压力范围」再判定；只要组分已知就应能直接判定。

## 3. 从零搭建的通用机制

以下为 Aspen 对象树的通用结构；**具体路径、端口名、节点写法以本机版本实测为准**：

- **组分表是二维表格**：对列节点逐个添加通常不可用；通用写法是对整表 `Elements.InsertRow(...)` 插行后用 `Elements.SetLabel(...)` 写入组分 ID（具体签名以本机 COM 类型库为准）。不要对同一 ID 重复插行（不会去重）。写入后读回或用导出报告验证。
- **建流股/建块**：Aspen 通用做法是以单串「名称!类型/模型」添加（如 `FEED!MATERIAL`、`B1!RadFrac`）；两参数写法在某些版本报错。端口连接在块 `Ports` 下按**纯流股名**添加。
- **端口名不能猜**：不同块类型的端口名不同（如精馏塔进料/馏出/塔底、换热器能量侧等）。先用枚举子节点的通用函数把端口名读出来再连；漏接端口是"输入不完整"的常见原因。
- **块/流股 与 Flowsheeting Options（Design-Spec/Calculator）的对象添加语法可能相反**（后者常需"ID + 类型"两参数）；勿混用。
- **每个能改变压力的块都要显式给出口压力/压降**：若某块出口压力默认 0，会造成压力网络非法或输入不完整——与 SKILL.md §7.1 压降规则一致：凡影响压力的单元都要按流体/设备/压力等级有依据地设置压降（见 `engineering-modeling-basics.md`）。
- **先最小闭环、再扩展**：从"最小可跑闭环"（必要组分 + 物性 + 进料 + 一个块 + 产物）开始验证，再逐步加块，便于定位问题。

## 4. 固体 / 盐析 / 结晶类任务的通用建模要素

任务涉及"析出固体/结晶/盐平衡"时，通用建模要素（不依赖版本）：
1. 固体组分 + 固体子流（全局流类型需允许固液共存；进料/产物中要有固体所在子流）；
2. 建立常规（溶解）组分 ↔ 固体组分之间的**平衡关系**（Aspen 中通常经 Chemistry/盐选项与溶解度表达）；
3. **溶解度数据来自教材/实验，不能臆造**；降温区间要保证体系进入过饱和；
4. 用固体分离/过滤单元把固体从母液中分出；母液循环须按 `general-verification-methods.md` §4 做循环收敛判定。

> 具体块类型、子流命名、Chemistry 配置路径以本机版本为准。此类体系常触发"焓被算成非物理值"的问题，务必按 `general-verification-methods.md` §2/§3 做基准验证。

## 5. 反应动力学的通用要点（与 `kinetic-reactor-input-workflow-320-322.md` 配合）

- **类型选择**：给的是正逆速率常数 k1/k2 的可逆动力学 → 用幂律类（POWERLAW/LHHW），**不要用 EQUIL**；EQUIL 只用于纯平衡（速率只由平衡常数约束）的反应。
- **教材 Arrhenius → Aspen 参数（通用换算）**：教材给 `k = A*exp(-E/RT)`。Aspen 幂律类常写作 `k = PRE-EXP*exp[-ACT-ENERGY/R*(1/T - 1/T-REF)]`。通用做法：**T-REF 取反应操作温度，PRE-EXP = 该温度下的 k 值**（避免超大指前因子造成数值刚硬/非物理解）；ACT-ENERGY 用 Aspen 该字段要求的能量单位填写（J 与 cal 换算 1 cal = 4.1868 J），最终以本机文档单位制/帮助确认。
- **计量/级数书写**：反应物写在反应计量段（系数为负），产物写在产物计量段（系数为正）；**速率级数（EXPONENT）通常只出现在反应物段**，产物段不写；级数与速率式一一对应。
- **文本注入陷阱**：在 `.inp`/`.bkp` 文本里手工注入带引号字符串（如 DESCRIPTION）时，**引号内不能跨行**——跨行未闭合会被解析器静默丢弃整段（表现为块/流程凭空消失，但导出文件看似正常）；注入后必须用"块数量 + 结果"双重校验。反应集注入后以"块真正执行 + 结果与教材/实验目标吻合"为准。

## 6. 官方示例底版的使用原则（第二原则）

官方 Examples Library（本机安装版自带）或任何"已收敛底版"：
- 正当用途：作**结构底版/校验基准**——学习某类模型怎么搭、端口怎么连、某参数放哪；
- 禁止照抄：底版中的组分、进料、塔板数、回流比、压力、温度、纯度目标等**全部数值**须按第一原则用当前任务的原理与需求重设；
- 采用任何底版前先说明它与你方案的结构差异与适用条件。
