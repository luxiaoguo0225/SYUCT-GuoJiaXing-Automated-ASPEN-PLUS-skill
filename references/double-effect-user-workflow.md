# 双效精馏搭建准则(用户指定,必须遵守)

用户要求把以下"搭建双效精馏的准则"固化到 skill 中。做任何双效/多效精馏拆塔任务前,
先按此准则执行,并把准则写入交付文档。

## 拓扑选择(最高优先)

- **双效精馏必须优先考虑串联**(第一个塔塔底产物 → 第二个塔进料)。
- **想要做并联(进料分流各处理一半)必须先询问客户**,得到客户同意后才能用并联。
- 串联在 EB/甲苯等低相对挥发度体系下,精制塔(HP)存在"回收 vs 纯度"权衡
  (见文末"与已验证案例的关系"),若串联无法同时满足回收+纯度,应告知客户并给出
  并联方案供客户选择,由客户决定。

## 必做流程(按顺序,共 6 步)

1. **先准备一个基准塔**:完整 RadFrac(带冷凝器/再沸器),记录:
   - 塔顶采出流股(总流量、各组分流量、组成)
   - 塔底采出流股(总流量、各组分流量、组成)
   - 冷凝器负荷、再沸器负荷(能耗基准)
2. **将一个基准塔拆成两个精馏塔(串联)**:
   - 第一个精馏塔的塔底产物 → 第二个精馏塔(进料)
   - 两个塔的塔顶采出物之和 = 基准塔的塔顶采出
   - 第二个精馏塔的塔底采出物 = 基准塔的塔底采出物
   - **两者数据偏差不能超过 5%**,否则重新拆塔(调整 D1/D2 分配)
3. **依据情况将两个塔改造为一个高压塔一个低压塔**:
   - 选择压力使高压塔塔顶温度 − 低压塔塔釜温度 ≥ 10~20°C(热集成温差)
   - 串联方向:低压塔塔底液 → 泵 → 高压塔进料(或反之)
4. **把步骤 2 的两个塔再沸器和冷凝器全部拆开**:
   - RadFrac 改 `CONDENSER=NONE REBOILER=NONE`(裸塔)
   - 外置冷凝器(Heater 全凝)、外置再沸器(Heater + Flash2 绝热闪蒸)
5. **让高压塔塔顶的气体与低压塔塔底进行热交换**:
   - HeatX(REB-HX):热侧 = 高压塔塔顶蒸汽(冷凝),冷侧 = 低压塔釜液(再沸)
   - 高压塔顶冷凝热 = 低压塔再沸热(热集成)
6. **双效塔负荷相比原精馏塔至少节能 35%**:
   - 节能 = (基准再沸 − 双效外部再沸)/基准再沸 ≥ 35%
   - 若不达标,回到步骤 3 重新设计低压/高压塔(压力、板数、回流)
   - **必要条件下可牺牲节能效果来保证组分回收率和质量纯度**(产品达标优先)

## 验收与排错

7. **流程模拟最后结果要读取 `.his` 文件,无任何隐藏错误**:
   - `.his` 中 `Summary of Simulation Errors` = 0 Severe / 0 Error / 0 Warning
   - **Aspen 控制面板不得有任何报错或警告**
   - 注意:`.his` 统计全程(含迭代瞬时消息);若迭代过程有瞬时 UDL03.3 干板等,
     需通过初值优化消除,不能交付"有瞬时错误但最终收敛"的版本
8. **遇到隐藏错误可调用调和功能(Reconcile)**:对流股和塔模块进行调和,赋予初值,
   尝试解决错误。`Reconcile()` 可更新撕裂流输入为收敛值,但效果在保存/重开后不保留,
   需在会话内验证;更可靠的方案是直接用手动收敛终值做撕裂流初值。

## 压降规则(全程强制)

- **除混合器(Mixer)、压力变送模块(泵/阀/压缩机)之外,所有模块必须考虑压力降**
- **压降用负值压力表示**:如换热器/冷凝器/再沸器在压力位置输入 `-0.05` = 压降 0.05 bar
- **不要直接给固定值**:必须先看流体相态、密度/黏度、流量、设备类型、操作压力、回流/再沸/循环返回压力裕量
- **常规经验值优先在 0.2 bar 左右**:正压下的换热器、冷凝器、再沸器、冷却器/加热器等,若无更详细压降计算或厂家数据,通常先按约 `-0.2 bar` 量级估算
- **小压降是例外,不是默认**:只有低压/真空侧、压力裕量很小的回流/再沸/循环返回线,或不能设置实际升压设备而会导致进料压力低于塔级时,才退到 `-0.01~-0.05 bar`
- **不得使用补偿泵**:不能为了"补偿压降导致的压力不足"而加泵;
  回流/再沸回塔压力不足先通过调塔压、塔压降和真实设备布置解决,确属压力受限时才用很小压降并说明依据
- 塔内压降用 `DP-STAGE` / `DP-COL`
- 唯一允许的泵是**物料输送泵**(如低压塔底液 → 高压塔进料),属压力变送模块

## 与已验证案例的关系

- 并联双效(eb_double_effect_heatx_final):0/0/0 零错误、节能 35%+、回收 99.99%、
  纯度 99.91%,全部达标
- 串联双效(eb_series_heatx_final):零错误 + 节能 35%(HP-REB 2.4)时纯度 98.4%;
  纯度 99.9% 时回收下降——这是 EB/甲苯低相对挥发度下精制塔的固有矛盾,
  若用户要求回收+纯度同时 ≥99.9%,优先选并联;若坚持串联,需明确告知此权衡
