## 吸收、汽提与相分离配置

| 常规逆流气液吸收 | 平衡级模拟用 RadFrac。常规无冷凝器、无再沸器吸收塔设 Condenser=None、Reboiler=None，气体在下部进入、贫吸收剂在上部进入。V14 采用标准算法且提供高级吸收塔选项时，启用 Absorber=Yes 并从原生文件回读。其他合法算法或版本按当前手册确认等效配置。实际带回流、再沸或级间冷却时，按真实设备配置 | 规定目标气体捕集率或尾气含量，优先以新鲜吸收剂量或可调循环量作为操纵量。两项同时给定时先检查它们是否由同一组分衡算决定。有循环时按外部边界算净捕集。按适用性核 Henry、液相非理想性和吸收热 |
| 有传质、填料或反应要求的吸收塔 | 需要预测传质或填料表现且有对应数据时选择可用的速率型模型，录入填料、传递、反应和实际压降等所需数据 | 传质模型的选择、数据和验证单列。平衡级结果可用于适用的流程衡算，设备尺寸或传质性能需要相应校核 |

<a id="flash-setup"></a>

### 闪蒸与澄清器操作步骤

1. **按出口选模块。** 一股气和一股液用 Flash2。气相和两股液都要单独引出时用 Flash3。只有两股液且在预期操作范围内确认无需排气时用 Decanter。气相是否形成还不确定时，先用 Flash3 在实际温度、压力和组成范围内检查。
2. **把调温和分相接开。** 用户要求绝热分相时，先用换热器（可用 Heater 表示冷却器）设置所需温度或热负荷，把真实出口接到分相器。需要形成两液相时，检查上游换热器的有效相设置允许相应的气液液或液液平衡。各设备压力或压降按实际计入一次。核对分相器接收的温度、压力、组成和焓。
3. **在分相器的 Input → Specifications 设操作条件。** 绝热时给出口压力（或按该模块约定输入压降）和零热负荷，核对压力单位、绝压基准和实际生效的热负荷。原生输入可见 `PRES=… DUTY=0.`。出口温度由焓与相平衡求出，压降或相态变化可使出口温度与入口不同。`T-EST` 只是计算初值。做定温定压平衡分析，或罐体本身有定温热交换时，可改用出口温度和压力，由 Aspen 计算热负荷。压力、温度和零热负荷不要同时作为固定规格。
4. **核结果再接后续。** 在块结果和各出口流股中核实际温压、相数、各相质量流量和关键组分质量分率。用组成识别油相和水相，分别核油相含水与水相的有机物损失。检查进出口总质量、各组分和能量闭合，绝热时核出口总焓流等于入口总焓流。预期某相却算出零流量时，先查实际温压与入口焓、有效相设置，再返回 [P00](../properties/index.md) 查相关 VLE、LLE 或 VLLE 及适用的二元参数。禁止用组分分割系数代替分相预测。

模块规格及相出口参见 [Aspen Plus Unit Operation Models Reference Manual](https://studylib.net/doc/26271514/aspenplus-manul) · [Aspen Plus User Guide](https://web.ist.utl.pt/ist11038/acad/Aspen/AspUserGuide10.pdf)
