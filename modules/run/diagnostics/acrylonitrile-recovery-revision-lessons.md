# 丙烯腈回收工段的续改检查

这些检查适用于同一 Aspen Plus 项目多轮变更进料、设备和采出位置，以及模型与衡算书同步修订。

<a id="requirements"></a>

## 冻结当前要求

- 记录各要求的生效、撤回或替代状态。物性方法、溶剂、采出位置、成品边界、产能和文件范围按用户最新有效指示执行。变更溶剂或分离原理前核对仍适用的约束。
- 使用文献进料时核对表格列、生产值或模拟值、工段边界、组分基准与缩放。改变总流量后回读绝对流量与分率，检查 Aspen 是否重新归一化。
- 从原生文件回读设备位号、端口及活动规范。改名或删设备后同步检查撕裂流、图例、Word 中的位号、表格和引用。

<a id="checks"></a>

## 交付前检查

- 分开核算塔内回收率、粗品回收率和合格成品的全工段回收率。全工段的分母取新鲜进料，分子取满足产品要求的最终采出。年产按成品组分流量和约定运行小时折算。
- 对吸收塔检查原生吸收设置及实际冷凝、再沸配置。绝热闪蒸核零热负荷、压力、相数、焓平衡与出口温度。只有液液分相职责时可用 Decanter。外置冷却器与分相器应采用工况所需的相数。
- 油相含水和水相含有机物是两个指标。按温度、压力、组成及相态核对互溶度，区分平衡溶解与机械夹带。
- 回读活动 Design Spec 的目标、实际值、操纵量和范围。回流比异常时检查分母、实际回流量及冷凝和再沸负荷。用冷重开、重新初始化和新历史检查最终 APWZ 与 BKP 的可复现性。

<a id="case"></a>

## 采出方案与循环中的设计规定

比较塔底直出、侧采及塔顶分相回用时，保持进料与验收基准可比。独立列出水、产品及关键杂质的净排出和内部循环量，再核纯度、总回收、产量和热负荷。冷凝器分采气液时以实际配置和采出核算回流比。

当塔内回收目标与循环中的产品质量目标存在耦合，可先用塔内设计规定调节采出，再用流程级 Design Spec 操纵一个有实际物理作用且独立的变量。检查计算顺序、活动状态、约束边界和两个残差。变更后的模型与衡算书应引用同版原生计算结果。
