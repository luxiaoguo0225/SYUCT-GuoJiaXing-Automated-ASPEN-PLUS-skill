## 塔设备设计规范

新建或重做塔时，先确定设备职责、目标组分、采出流股和相态，再从下表选正式设计规范。操纵量是可检验的候选，须经自由度、灵敏度、操作边界和当前设备配置确认。

| 塔的职责 | 优先核对的正式设计规范 | 优先试的独立操纵量 |
|---|---|---|
| 普通两产品精馏或粗分塔 | 塔顶轻关键组分回收率和塔底重关键组分回收率。产品已有纯度合同的，按合同以纯度或指定杂质上限替换对应目标 | 塔顶或塔底采出量配合回流量或回流比。只有两个出口时，塔顶量与塔底量不能互作两条独立操纵量 |
| 多产品或有侧采的回收塔 | 对每个承担分离任务的产品指定组分和出口，例如塔顶主组分回收率及侧线副产品回收率。必要时附侧采质量指标 | 顶部总采出量与独立侧采量优先试。按需配合回流，核对侧采级、液相或气相及总采出约束 |
| 末端精制塔 | 优先给合格产品同时设组分质量回收率和质量纯度，或按合同改用具体杂质上限。产品可在塔顶、塔底或侧线，按轻重端净去向选择 | 产品采出量配合回流或另一独立采出量。侧线产品先试侧采量和塔顶量或回流比，核查两项目标是否分别有响应 |
| 脱轻、脱重、脱酸或脱氢氰酸塔 | 指定杂质从哪股排出，并约束有效产品损失。例如轻杂质塔顶回收率与主组分塔底回收率。若交付规格是产品杂质上限，直接在该产品流股上核对 | 塔顶或对应侧线采出量配合回流或另一可用操作量。核不凝气、液体产品和釜液各自实际流向 |
| 萃取精馏塔 | 指定萃取段目标产品的回收率及质量纯度或残余杂质上限，另核夹带溶剂及实际溶剂比 | 塔顶量配合回流，或用有真实物料来源的萃取剂流量。操纵闭环溶剂量时由全流程唯一变量控制，必要时用流程级 Design Spec |
| 溶剂再生塔 | 约束返回溶剂的质量纯度或残余水、杂质含量。需要限制补料或尾气损失时，加再生溶剂回收率或损失指标 | 塔顶量配合回流或其他独立可调操作量，核再生温位、循环排污与补料 |
| 吸收塔、汽提塔、液液萃取塔 | 以目标物捕集率、尾气排放、贫液残余或净萃取率为主，按[吸收与相分离配置](M11-mass-transfer.md#absorber-and-phase-separation)选择 | 吸收剂、汽提介质或萃取剂的实际流量。只有实际具备冷凝或回流设备时才引入回流规格 |

对变压精馏、共沸精馏及塔顶液液分相回流，先用相图确认路线可达，再选规格。涉及循环时，验证各塔出口质量、循环闭合、产品总回收率及杂质净排出。塔的物理功能、目标和可用操作量决定规格数。

- **关键组分回收率。** 指定塔顶或塔底产品流股和组分。关键组分优先以99%以上为目标，具体阈值按用户要求和该塔的分离任务确定。注明质量或摩尔基准，并以指定产品中该组分流量除以同基准下该组分的塔进料总流量核算。
- **产品质量纯度。** 指定塔顶或塔底产品流股、目标组分及其质量分数目标。用该组分质量流量除以指定产品总质量流量核对。
- **回流比。** 适用时记录用户要求的数值、上限或允许范围，并核对实际回流比及其定义。回流比可作为固定操作条件或在设计规范中求解所用的操纵量。固定回流比时不得同时将其设为操纵量。无回流的塔按其分离任务选规格。

逐塔记明操作规格、活动 Design Spec、验收指标及三者的关系。质量纯度优先使用原生 MASS-FRAC，组分质量回收率优先使用原生 MASS-RECOV，并读回实际定义、组分、分母、出口与基准。活动规范与可用的独立操纵变量逐项对应。给定设计目标和边界时，先用物料衡算排查矛盾，再检查操纵量是否能改变各目标，避免两个规范约束同一分离切割。用户要求最终双规范时，可先用一项定位可行点，再启用第二项并复核两项残差、操纵量触界和变量归属。规格不可同时达到时，报告未达标项和限制，保留原目标。

**Design Spec 的目标值与 Vary 边界。** 本规则也适用于流程级 Design Spec。

- 目标采用用户指定值或有依据的工程设定，通常最多四位有效数字。例如质量分数目标可录为 `0.9999`，名义值为 `0.01` 时直接录入 `0.01`。初算得到的 `0.0099999996` 这类浮点尾数不用于正式目标。用户明确规定精度、目标或合格边界时按原要求录入，取整不得改变验收口径。
- 回流比、采出量等 Vary 上下限取能覆盖预计可行点的工程区间，单位明确，优先用整数或简洁小数。必要时可在物料、设备和操作可行范围内适度放宽，给求解保留余量。扫描所得边界点只用于判断可行范围和设置初值。
- 按原生字段读回实际录入的目标及上下限，复算并核对残差、操纵量是否触界及产品指标。求解结果可保留原始精度供复核，求解容差按原要求执行。

再沸器和冷凝器热负荷不得作为正式设计目标，也不得以固定热负荷替换回收率、纯度或回流比要求。读取求解后的负荷，用于能量衡算、热源冷源可行性和设备核算。最终冷重开复算时，逐塔读回实际规格、回收率、质量纯度和回流比，并联合检查顶底温、冷凝及再沸负荷、夹带和压差。

精制采出变更时，在同一进料、物性与合格产品基准下比较塔底直出、侧采、塔顶分相回用和直接掺混。以目标杂质净排出、纯度和全工段回收同时验收。高回流比复核实际采出分母、回流量和负荷，按运行数据查相邻塔。见[回收精制案例](diagnostics/acrylonitrile-recovery-revision-lessons.md#case)。
