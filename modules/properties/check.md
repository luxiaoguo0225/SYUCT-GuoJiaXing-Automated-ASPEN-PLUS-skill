# P01 物性前置轨道检查

所属：[P00独立物性轨道](index.md)，位于流程模拟之前；[O02](../output/check.md)只回查其有效性，不代替前置执行。触发：录入或改变组分、纯组分库、物性方法、二元参数/数据源、Henry/电解质设置后立即调用；在搭塔、动力学单元测试或使用这些物性结果前完成。温压/组成包络、相数或溶剂改变也必须重验受影响部分。最终O02不能替代此关口。

## 交接输入

只接收冻结要求、当前输入/有效设置快照、实际参数回读、来源原文/记录、必要的相平衡或物性计算输出。快照包含组分真实身份、全局和局部方法、所需组分对/方向、物性类别、相态及T/P/组成范围。不以口头说明代替实际回读和来源证据。

按实际方法列出必需的纯组分、二元及其他物性记录与字段。界面可选字段按方程和用途判定。缺失的必需记录进入补源或重新选型。记录须逐对/逐方向展开，不以“选了NRTL/勾选数据库”代替审计。

## 必需检查

| 固定检查id | 检查与可观测证据 |
|---|---|
| PROP-SOURCES | 每个必需组分对是否实际选用来源：原生数据库/版本/记录id/查找顺序/最终命中。USER、手工覆盖或自行回归录入一律不接受；文献仅用于验证与选源，不能据其允许USER。区分纯组分数据库与二元参数库、可用来源与已生效来源；回读来源字段和数值字段，不能仅看setter成功。 |
| PROP-ZEROS | 扫描实际生效记录的缺失、null、默认回退及0值，逐项登记组分对、字段、数值、单位、来源和字段用途。必需数据出现无依据的0时退回P00追溯和比较适用来源。对有效的固定零、拟合约束零或未启用项分类记录并按当前验收要求处理。无来源的0不作为有效数据。 |
| PROP-APPLICABILITY | 来源相关式/模型、组分方向、单位、温度形式、T/P/组成范围和适用相与当前方法一致；禁止混用NRTL/UNIQUAC等不同参数形式或从多套记录任意拼系数。 |
| PROP-PHYSICAL | 按任务审核已选方法的适用性。普通流程用方法选型依据、代表性工况的相态及关键分离趋势核对，范围清楚且支持当前用途即可判定。Aspen 原生参数与文献拟合值不同本身不构成失败。共沸、分相或外推左右结论时针对该项补证。用户要求实验复现或工业验证时另按冻结要求取证。仅库内有参数或软件收敛不构成适用性依据。 |
| PROP-READBACK | 当前原生副本保存/独立重开后回读方法、各组分对来源、系数及有效范围，确认导入/保存未把选择丢失或默认为别的来源；回读与验证快照字节及身份绑定。 |

按[二元输入完成判断](index.md#binary-input-decisions)给每个必需对记录实际命中来源、是否留用或换源、是否采用获准估算，以及保存重开后的结论。

### 零值的处理边界

“换来源”针对物性数据或必需拟合数据，不是强行让每一格都非零。公式规定固定为0的项、明确不参与本相关式的项等，必须有模型定义和原始来源依据，单列为结构项；不得把未知的0改名为结构项。组分含量为0、未启用字段等也不是二元物性数据，不纳入“换库消零”。

若必需字段的0缺少原始依据，先退回P00查清来源、字段用途和适用替代。候选比较保留完整记录、适用性与结果。没有可靠替代，或可靠来源确实给出0且仍无法满足本任务验收时，保留原始记录并报告未通过，不编造非零值、不零填缺项、不为消零拼凑系数。换源后重新回读、重验物性与相图，再复算所有受影响结果。

## 输出和返回

在本会话中按[阶段格式](../shared/validation-stages.md)生成validation_stage=properties的合同与证据，五项均为必需review且不能NOT_APPLICABLE。PROP-SOURCES须包含“全部可用源先启用”的回读及最终命中；PROP-APPLICABILITY须有实际必需二元对及其记录的适用性审计。确需换源时给出候选比较，已有适用的完整记录直接核验。PROP-PHYSICAL 的通过范围按当前用途写清，独立实测是否验证、验证到何种工况另记。阶段候选的property_snapshot及五项证据绑定要求见P00。逐项记录审计、零值、换源候选及未解决项，运行check_delivery.py。全部通过仅CONTINUE，失败或缺证据返回P00（PROPERTIES）。已明确授权的[原生估算搭建与数值联算](index.md#native-estimate-diagnostic)按P00单列，保留正式物性验收结果。无需新agent、身份声明或隔离记忆。

最终O02核对当前物性子快照及范围仍与阶段报告一致；变更使旧证据失效，不能改哈希标签沿用。

原理：[物性、来源与参数回归](../../references/textbook-properties-and-boundaries.md)、[相图前置](../../references/phase-diagram-before-distillation.md)、[模型与能量诚信](../../references/convergence-separation-and-energy-integrity.md)。原理/案例资料仍保留原证据等级。

## 执行顺序与准入

按[P00](index.md#method-selection-and-binary-gate)先择定合适方法。对所需二元表全源启用并逐对查缺、查零、核实际来源和适用范围，必要时比较兼容记录。保存并独立重开回读，按本次用途核关键相行为。未知零值必须追溯/换源，无可靠替代则保留未通过，不能靠任意非零值满足检查。结构性零项有原始依据才可分类，不能把“合理参数不为零”推成所有温度展开项必须非零的物理定律；用户更严格约束仍须满足或报告未达成。

P01的CONTINUE仅允许调用流程准入，不是直接DELIVER。check_process_gate.py重验五项及当前子快照一致后才能进入R00；仅“数值验收DELIVER”、全源已勾选、某套实验拟合较好或原生文件可打开均不能替代本关口。

**USER禁用是必需项。** PROP-SOURCES遇到任何USER、手工/自行回归覆盖须FAIL，来源不明为UNVERIFIED；其他参数/物性即使已有数据也不能抵消该失败。审计全部当前有效输入，冻结与独立回读快照均需原生数据库来源、USER计数0及未知来源计数0；流程准入脚本会再次拒绝USER，不存在allow_user豁免。历史模型只读诊断不等于准许运行它。
