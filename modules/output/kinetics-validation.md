# K01 动力学录入后立即检查

所属：[O02检查模块](check.md)。触发：录入/改变反应集、速率式、A/E/Tref、正逆反应/吸附项、单位、反应相、催化剂及速率基准后立即调用。先完成[P01物性关口](properties-validation.md)，再用独立反应器测试验证本轮动力学，不能等全流程搭完再比较转化率/选择性。

“录入后立即”包括为验证建立最小独立反应器并运行，不能因尚无反应器输出而直接判通过。测试副本、已知边界及必要假设公开；检查使用副本取证，参数或正式反应集修复返回R00/M03。

## 必需输入和检查

| 固定检查id | 检查与可观测证据 |
|---|---|
| EARLY-PROPERTIES | 核对P01的CONTINUE及当前有效物性子快照；缺失、过期或范围不符时先返回物性关口。 |
| KIN-INPUT | 原始动力学文献/DOI、方程/表格/页码、催化剂与状态、适用温压/组成/传递条件；实际反应网络、化学计量与元素守恒、可逆性、速率/浓度或分压/活度基准、单位、A/E/Tref及反应相回读。不能只替换A/E忽略基准。 |
| KIN-RATES | 在文献范围内选择有代表性的低/中/高温及组成，独立计算原文速率与Aspen实际速率，核单位、符号、平衡极限、吸附项和温度依赖。计算/积分程序、输入和实际结果作为证据，不仅交手算结论。 |
| KIN-LITERATURE | 尽量重现原文催化剂、T/P、进料比、含水/杂质、反应相、空间时间/催化剂装量、热边界等条件；逐点比较实测与预测转化率X、选择性S，必要时收率Y、速率和轴向/时间轨迹。记录实际值、文献值、差异、定义、单位及来源位置，按来源精度/不确定度或事先有据冻结的阈值判断。 |
| KIN-INDUSTRIAL | 独立查找可追溯工业经验/装置/中试数据，写出来源、工艺、催化剂、操作条件与X/S口径。将本模型当前工况与适用范围比较；相邻技术/不同催化剂仅作有标识的类比，不以用户目标或通用百分比代替工业依据。证据不足或不能建立可比性即UNVERIFIED。 |
| KIN-SELECTIVITY | 明确单程/全厂、摩尔/质量/碳基、净生成量/出口总量和化学计量归一基准；核副反应、串并联、产物入口夹带、循环和副产物去向。只有主反应时得到的100%选择性是结构结果，不能当成工业选择性验证。缺副反应证据时该项不得PASS。 |
| KIN-RUN | 当前独立反应器实际执行、有效设置和新run_id；完整.his及必要的正常.rep，零Severe/Error/Warning；同时有独立元素/物料、能量与反应进度核算。不能用RStoic规定转化、产品Design Spec或人为分配代替动力学预测。 |

KIN-RUN采用history检查；其余为review。缺少文献数据、工业可比数据、所需副反应或实际执行证据，都不能用“经验上合理”补成PASS。

## 评价指标和比较条件

选择一个明确反应物A。单程摩尔转化率常用 `X_A=(F_A,in-F_A,out)/F_A,in`；入口量为0或存在生成A的复杂网络时先重定评价口径，不能除零。若采用同一目标反应计量归一，`S_P,A=ΔF_P*abs(nu_A/nu_P)/(F_A,in-F_A,out)`、`Y_P,A=ΔF_P*abs(nu_A/nu_P)/F_A,in`，仅在同一口径和分母有效时才有 `Y=X*S`。其他定义按原文，不强行套此式，不裁剪越界值掩盖问题。

分别报告“文献条件下复现”与“当前工业工况下适用性”。实验室与工业条件不同，不能强求两者数值相同；应有来源支持的条件换算/独立测试和范围说明，无法建立可比性则未验证。反应平衡不等于有限停留时间动力学，单程与循环总转化不能互换。阈值在比较前冻结，不能为通过而放宽或任意换文献。

## 不符时的返回路径

按可观测证据返回M03+M01/M05/M08/M09+M15：先核单位/基准/实现、反应网络、物性、传递与热边界，再由R00选择来源适用、网络较完整的新动力学或修正实现，重新录入并立即重验。不得为凑工业转化率/选择性任意调A/E、停留时间或规定反应结果；有依据的回归必须区分标定数据与独立验证数据，不能用拟合点证明外推有效。

按[阶段格式](../shared/validation-stages.md)使用validation_stage=kinetics。物性前置检查和六项动力学检查全部有效，check_delivery.py才返回CONTINUE；否则RUN，回M03及相关模块修复。未通过前不继续全流程循环/优化。关口只覆盖测试条件；最终O02仍核当前快照、冷重开和全流程约束。全程在同一会话执行，不创建独立验证agent。
